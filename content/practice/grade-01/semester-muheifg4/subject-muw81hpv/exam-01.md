## 문제 1

**참고 자료:** 2017·2018 중간고사 계열.

> [!QUIZ]
> 다음 프로그램의 최종 배열 값과 전체 출력을 쓰시오. 함수가 호출될 때마다 k와 m의 값이 어떻게 달라지는지 표로 설명하시오.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> int func(int a[], int k)
> {
>     static int m = 0;
>
>     a[k] = a[k] + k;
>
>     if (m == 0)
>         k = k + 1;
>
>     m = (m + 1) % 2;
>     return k;
> }
>
> int main()
> {
>     int a[] = {3, 3, 2, 2, 1};
>     int i = 0;
>
>     while (i < 5)
>         i = func(a, i);
>
>     for (int j = 0; j < 5; j++)
>         cout << a[j] << ", ";
> }
> ```

> [!ANSWER]
> 최종 배열은 **{3, 5, 6, 8, 9}**입니다. 실제 출력에는 마지막 원소 뒤에도 쉼표와 공백이 붙습니다.
>
> ```text
> 3, 5, 6, 8, 9,
> ```
>
> `m`은 `static`이므로 호출이 끝나도 값이 유지되고 `0 → 1 → 0 → 1 ...`로 반복됩니다.
>
> | 호출 | 시작 k | 시작 m | 변경되는 원소 | k 증가? | 반환 k |
> |---:|---:|---:|---|:---:|---:|
> | 1 | 0 | 0 | `a[0] += 0` → 3 | O | 1 |
> | 2 | 1 | 1 | `a[1] += 1` → 4 | X | 1 |
> | 3 | 1 | 0 | `a[1] += 1` → 5 | O | 2 |
> | 4 | 2 | 1 | `a[2] += 2` → 4 | X | 2 |
> | 5 | 2 | 0 | `a[2] += 2` → 6 | O | 3 |
> | 6 | 3 | 1 | `a[3] += 3` → 5 | X | 3 |
> | 7 | 3 | 0 | `a[3] += 3` → 8 | O | 4 |
> | 8 | 4 | 1 | `a[4] += 4` → 5 | X | 4 |
> | 9 | 4 | 0 | `a[4] += 4` → 9 | O | 5 |

## 문제 3

**참고 자료:** 2020 중간고사 메모와 2017·2018 배열 문제의 오류 판별 설명을 재구성.

> [!QUIZ]
> 다음 세 코드를 각각 독립적으로 판단하시오. 컴파일 오류인지, 실행 시 정의되지 않은 동작인지 쓰고 이유를 설명하시오.
>
> (1)
>
> ```cpp
> int a[3] = {1, 2, 3, 4};
> ```
>
> (2)
>
> ```cpp
> int a[5];
> a[5] = 10;
> ```
>
> (3)
>
> ```cpp
> void add(int a[], const int &k) { k = k - 1; }
> ```

> [!ANSWER]
> #### 1. 배열 선언 크기보다 초기값이 많음
>
> ```cpp
> int a[3] = {1, 2, 3, 4};
> ```
>
> → **컴파일 오류** (`too many initializers`)
>
> #### 2. 배열 범위를 벗어난 인덱스 접근
>
> ```cpp
> int a[5];
> a[5] = 10;
> ```
>
> 족보에서는 흔히 **runtime error**로 분류합니다.
>
> > 표준 C++에서 더 정확한 표현은 **undefined behavior(정의되지 않은 동작)** 입니다. 반드시 실행 중 오류가 발생한다고 보장되지는 않습니다. 시험에서는 교수님 수업 기준 표현을 우선 확인하세요.
>
> #### 3. `const`로 받은 값을 함수에서 수정
>
> ```cpp
> void add(int a[], const int &k)
> {
>     k = k - 1;   // 오류
> }
> ```
>
> → **컴파일 오류**. `const` 참조를 통해 값을 수정할 수 없습니다.

## 문제 7

**참고 자료:** 2017·2018·2020 중간고사 반복문 변환 항목. 대표 코드의 정확한 출제 연도는 보완본에 명시되지 않음.

> [!QUIZ]
> 다음 while문을 같은 동작의 for문으로 바꾸시오. 반복문 종료 후 sum과 j의 값도 쓰시오. 두 변수는 반복문 밖에서도 사용할 수 있어야 한다.
>
> ```cpp
> int sum = 0;
> int j = 0;
>
> while (j <= 10) {
>     sum = sum + j;
>     j++;
> }
> ```

> [!ANSWER]
> ```cpp
> int sum = 0;
> int j = 0;
>
> for (; j <= 10; j++) {
>     sum = sum + j;
> }
> ```
>
> 최종 `sum`은 `0 + 1 + ... + 10 = 55`이며, 원본처럼 반복문 밖의 `j`도 유지되어 종료 후 11입니다.
>
> ### 변환 규칙
>
> ```cpp
> 초기식;
> while (조건식) {
>     실행문;
>     증감식;
> }
> ```
>
> ↕
>
> ```cpp
> for (초기식; 조건식; 증감식) {
>     실행문;
> }
> ```

> [!QUIZ]

>
> ```cpp
> #include <iostream>

>
> void hi(int &x, int y)
> {
>     x = x + 10;
>     y = y - 10;
> }
>
> int main()
> {
>     int x = 2;
>     int y = 3;
>
>     int &var1 = x;

>

> int &var2;
> ```
>

> ```
>
> ### 수정 후 출력
>
> ```text
> 12 3
> ```
>
> - `x` → `int&`로 전달 → 원본 변경
> - `y` → 값으로 전달 → 함수 내부 복사본만 변경

## 문제 10

**참고 자료:** 2023 중간고사 2번.

> [!QUIZ]
> 다음 물음에 답하시오.
>
> 1. 컴파일 오류가 발생하는 문장을 찾아 수정하시오.
> 2. 수정한 프로그램의 출력을 쓰시오.
> 3. i의 선언을 const int i = 2;로 바꿀 수 있는지, 관련된 문장을 모두 들어 설명하시오.
>
> ```cpp
> #include <iostream>
>
> void fun(int &r, int v)
> {
>     r = r + 100;
>     v = v - 100;
> }
>
> int main()
> {
>     int i = 2;
>     int j = 3;
>     int &r1 = i;
>     int &r2;
>     r2 = j;
>
>     fun(i, j);
>
>     std::cout << "i : " << i << std::endl;
>     std::cout << "j : " << j << std::endl;
> }
> ```

> [!ANSWER]
> ### 1) 잘못된 문장
>
> ```cpp
> int &r2;
> ```
>
> 참조 변수는 선언할 때 바로 참조 대상을 지정해야 하므로 컴파일 오류가 발생합니다.
>
> ### 2) 수정
>
> ```cpp
> int &r2 = j;
> ```
>
> 이렇게 수정하면 뒤의 `r2 = j;`는 불필요하지만 문법적으로는 실행 가능합니다.
>
> ### 3) 출력
>
> `fun(i, j)`에서 첫 번째 인수 `i`는 참조로 전달되고 두 번째 인수 `j`는 값으로 전달됩니다.
>
> ```text
> i : 102
> j : 3
> ```
>
> ### 4) `const int i = 2;`로 바꿀 수 있는가?
>
> 불가능합니다. `int &r1 = i;`도 수정 가능한 참조에 상수를 연결하므로 오류입니다. 또한 `fun`의 첫 번째 매개변수는 수정 가능한 참조 `int &r`이므로 `const int`를 전달할 수 없습니다.
>
> ```cpp
> const int i = 2;
> fun(i, j);   // 컴파일 오류
> ```

## 문제 15

**참고 자료:** 2023 중간고사 3번.

> [!QUIZ]
> 다음 물음에 답하시오.
>
> 1. 같은 반환값을 구하는 반복문 기반 함수를 작성하시오.
> 2. g(3)을 구하시오.
> 3. 조건을 x < 0으로 바꾸었을 때 g(100)의 값을 점화식으로 구하시오.
>
> ```cpp
> int g(int x)
> {
>     if (x <= 0)
>         return x + 1;
>     else
>         return g(x - 1) + g(x - 1) + g(x - 1);
> }
> ```

> [!ANSWER]
> ### a) 반복문 버전
>
> `x > 0`일 때 `g(x) = 3g(x-1)`이고 `g(0)=1`입니다.
>
> ```cpp
> int g(int x)
> {
>     if (x <= 0)
>         return x + 1;
>
>     int result = 1;
>
>     for (int i = 0; i < x; i++)
>         result *= 3;
>
>     return result;
> }
> ```
>
> ### b) `g(3)`
>
> ```text
> g(0) = 1
> g(1) = 3
> g(2) = 9
> g(3) = 27
> ```
>
> **정답: `27`**
>
> ### c) 조건이 `x < 0`이면
>
> 이 경우 `x = 0`은 `else`로 들어가며,
>
> ```text
> g(0) = g(-1) + g(-1) + g(-1)
>       = 0 + 0 + 0

> ```
>
> 따라서 이후 모든 양의 정수에서도 결과는 0입니다.
>
> **정답: `g(100) = 0`**
>
> 이는 점화식으로 구한 값입니다. 같은 재귀 호출을 세 번씩 반복하므로 실제로 실행해서 확인하기에는 호출 수가 지나치게 많습니다. 원래 조건의 함수도 결과가 `int` 범위를 넘는 입력에서는 정수 오버플로에 주의해야 합니다.

## 문제 17

**참고 자료:** 2017 자료의 추가 출제 가능 항목. 실제 기출로 확인된 문항은 아니며, (3)·(4)는 연습용으로 추가.

> [!QUIZ]
> 다음 네 문장이 실행된 직후의 x 값을 각각 쓰고, 뒤쪽 식이 실행되는지 설명하시오.
>
> ```cpp
> int x = 0;
> false && (++x);  // (1)
> true  || (++x);  // (2)
> true  && (++x);  // (3)
> false || (++x);  // (4)
> ```

> [!ANSWER]
> **(1) 0, (2) 0, (3) 1, (4) 2.**
>
> - `false && ...`는 앞이 이미 거짓이므로 전체가 무조건 거짓 → 뒤를 확인하지 않음
> - `true || ...`는 앞이 이미 참이므로 전체가 무조건 참 → 뒤를 확인하지 않음
>
> 즉, **결과를 결정하기 위해 뒤 식을 볼 필요가 없으면 뒤 식은 실행되지 않습니다.**
>
> (3)과 (4)는 앞의 값만으로 전체 결과를 결정할 수 없어 뒤 식을 실행한다.
