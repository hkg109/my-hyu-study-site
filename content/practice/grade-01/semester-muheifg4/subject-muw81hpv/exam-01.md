## M1. 반복문 + 조건문 출력

### 문제
다음 C++ 코드의 출력을 쓰시오.

```cpp
#include <iostream>

void main()
{
    int y = 0;

    for (int i = 5; i > 0; i--) {
        if (i % 3 == 1)
            y++;
        else
            y += i;

        std::cout << "y = " << y << "\n";
    }
}
```

> [!QUIZ]
> **M1. 반복문 + 조건문 출력 · 확인 1** — 정답 보기. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **정답 보기**
>
> ```text
> y = 5
> y = 6
> y = 9
> y = 11
> y = 12
> ```
> 
> ### 계산
> 
> | i | 조건 `i % 3 == 1` | 수행 | y |
> |---:|:---:|---|---:|
> | 5 | X | `y += 5` | 5 |
> | 4 | O | `y++` | 6 |
> | 3 | X | `y += 3` | 9 |
> | 2 | X | `y += 2` | 11 |
> | 1 | O | `y++` | 12 |
> 
> > 최종값만 묻는다면 **12**이지만, 실제 코드에는 `cout`이 반복문 안에 있으므로 전체 출력은 위 5줄입니다.

## M2. 참조 변수와 함수 매개변수 오류 찾기

### 문제
다음 코드에 대해 답하시오.

1. 컴파일 오류를 발생시키는 문장을 찾는다.
2. 코드를 수정한다.
3. 수정된 코드의 출력을 쓴다.
4. `int i = 2;`를 `const int i = 2;`로 바꾸어도 되는지 설명한다.

```cpp
#include <iostream>

void fun(int &r, int v)
{
    r = r + 100;
    v = v - 100;
}

void main()
{
    int i = 2;
    int j = 3;
    int &r1 = i;
    int &r2;
    r2 = j;

    fun(i, j);

    std::cout << "i : " << i << std::endl;
    std::cout << "j : " << j << std::endl;
}
```

> [!QUIZ]
> **M2. 참조 변수와 함수 매개변수 오류 찾기 · 확인 2** — 정답 보기 — 인쇄된 코드 기준. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **정답 보기 — 인쇄된 코드 기준**
>
> ### 1) 핵심 오류
> 
> ```cpp
> int &r2;
> ```
> 
> 참조 변수는 선언과 동시에 반드시 참조 대상을 지정해야 합니다.
> 
> ```cpp
> int &r2 = j;
> ```
> 
> 으로 고쳐야 합니다.
> 
> ### 2) 수정 코드
> 
> ```cpp
> #include <iostream>
> 
> void fun(int &r, int v)
> {
>     r = r + 100;
>     v = v - 100;
> }
> 
> int main()
> {
>     int i = 2;
>     int j = 3;
>     int &r1 = i;
>     int &r2 = j;
> 
>     fun(i, j);
> 
>     std::cout << "i : " << i << std::endl;
>     std::cout << "j : " << j << std::endl;
> 
>     return 0;
> }
> ```
> 
> ### 3) 출력
> 
> ```text
> i : 102
> j : 3
> ```
> 
> - `r`은 참조 매개변수 → `i`가 실제로 변경됨
> - `v`는 값 매개변수 → 함수 안에서 바뀌어도 `j`는 그대로
> 
> ### 4) `const int i = 2;`로 바꿀 수 있는가?
> 
> **No.**
> 
> ```cpp
> int &r1 = i;
> fun(i, j);
> ```
> 
> 둘 다 `i`를 **수정 가능한 `int&`**에 연결하려 하므로 `const int`를 사용할 수 없습니다.
> 
> ### 표준 C++ 주의
> 원본 시험지의 `void main()`은 수업 자료 표기입니다. **표준 C++에서는 `int main()`**을 사용합니다.

> [!QUIZ]
> **M2. 참조 변수와 함수 매개변수 오류 찾기 · 확인 3** — 스캔본 학생 필기에 보이는 다른 해석. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **스캔본 학생 필기에 보이는 다른 해석**
>
> 스캔본 필기에는 두 번째 매개변수도 참조로 바꾸려 한 흔적이 있습니다.
> 
> ```cpp
> void fun(int &r, int &v)
> ```
> 
> 이렇게 바꾼다면 출력은 다음과 같습니다.
> 
> ```text
> i : 102
> j : -97
> ```
> 
> 다만 **인쇄된 `int v` 자체는 문법 오류가 아니므로**, 족보 본답은 인쇄 코드 기준인 `j : 3`으로 정리했습니다.

## M3. 재귀함수 → 반복문 변환

### 문제
다음 함수가 주어져 있다.

```cpp
int g(int x)
{
    if (x <= 0)
        return x + 1;
    else
        return g(x - 1) + g(x - 1) + g(x - 1);
}
```

다음에 답하시오.

1. 위 재귀함수와 동일한 결과를 내는 **반복문 기반 함수**를 작성하시오.
2. `g(3)`의 반환값을 구하시오.
3. 조건을 `x <= 0`에서 `x < 0`으로 바꾸었을 때 `g(100)`의 반환값을 구하시오.

> [!QUIZ]
> **M3. 재귀함수 → 반복문 변환 · 확인 4** — 정답 보기. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **정답 보기**
>
> ### 핵심 관계
> 
> `x > 0`이면
> 
> ```text
> g(x) = 3 × g(x - 1)
> ```
> 
> 이고
> 
> ```text
> g(0) = 1
> ```
> 
> 이므로
> 
> ```text
> g(x) = 3^x   (x > 0)
> ```
> 
> ### 1) 반복문 버전
> 
> ```cpp
> int g(int x)
> {
>     if (x <= 0)
>         return x + 1;
> 
>     int result = 1;
> 
>     for (int i = 0; i < x; i++)
>         result *= 3;
> 
>     return result;
> }
> ```
> 
> ### 2) `g(3)`
> 
> ```text
> g(3) = 3 × 3 × 3 = 27
> ```
> 
> **정답: 27**
> 
> ### 3) 조건이 `x < 0`으로 바뀌면?
> 
> ```text
> g(0) = g(-1) + g(-1) + g(-1)
>      = 0 + 0 + 0
>      = 0
> ```
> 
> 따라서 그 위의 모든 값도 0입니다.
> 
> **정답: `g(100) = 0`**
>
> 수학적인 반환값은 0이지만, 원래 재귀 코드는 같은 호출을 세 번씩 반복하므로 실제 실행에는 매우 많은 시간이 걸립니다. 원래 조건의 양수 입력에서도 결과가 `int` 범위를 넘으면 정수 오버플로에 주의해야 합니다.

## M4. 배열 내적 `inner_product`

### 문제
두 정수 수열의 내적을 다음과 같이 정의한다.

```text
p = Σ(a_i × b_i)
```

1. 배열 `a`, `b`와 크기 `n`을 받아 내적을 계산하는 `inner_product` 함수를 작성하시오.
2. `main`에서 배열 `a`, `b`의 내용과 `prod` 값을 `cout`으로 출력하시오.
3. 출력 코드는 `n = 4`에만 고정되지 않고 다른 `n`에서도 동작해야 한다.

```cpp
#include <iostream>

int inner_product(int a[], int b[], int n)
{
    // implement inner_product
}

int main()
{
    int n = 4;
    int a[] = {3, 6, 2, 1};
    int b[] = {1, 4, 2, 6};

    int prod = inner_product(a, b, n);

    // display prod, a, b
}
```

> [!QUIZ]
> **M4. 배열 내적 `inner_product` · 확인 5** — 정답 코드 보기. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **정답 코드 보기**
>
> ```cpp
> #include <iostream>
> 
> int inner_product(int a[], int b[], int n)
> {
>     int sum = 0;
> 
>     for (int i = 0; i < n; i++)
>         sum += a[i] * b[i];
> 
>     return sum;
> }
> 
> int main()
> {
>     int n = 4;
>     int a[] = {3, 6, 2, 1};
>     int b[] = {1, 4, 2, 6};
> 
>     int prod = inner_product(a, b, n);
> 
>     std::cout << "a : ";
>     for (int i = 0; i < n; i++)
>         std::cout << a[i] << ' ';
>     std::cout << '\n';
> 
>     std::cout << "b : ";
>     for (int i = 0; i < n; i++)
>         std::cout << b[i] << ' ';
>     std::cout << '\n';
> 
>     std::cout << "prod : " << prod << '\n';
> 
>     return 0;
> }
> ```
> 
> ### 내적 계산
> 
> ```text
> 3×1 + 6×4 + 2×2 + 1×6
> = 3 + 24 + 4 + 6
> = 37
> ```
> 
> **`prod = 37`**

## M5. 포인터 + 배열 + `static` 지역변수

### 문제
다음 프로그램에 대해 답하시오.

```cpp
#include <iostream>
using namespace std;

int fun(int k, int *p)
{
    int m = 1;
    *(p + k) = k + p[k];

    if (m != 0)
        k = k + 1;

    m = (m + 1) % 2;
    return k;
}

int main()
{
    int s[5] = {1, 4, 4, 4, 4};
    *s += 4;

    int j = 0;
    while (j < 5)
        j = fun(j, s);

    return 0;
}
```

1. 실행 후 `s[0] ~ s[4]`의 값을 구하시오.
2. `int m = 1;`을 `static int m = 1;`로 바꾸면 최종 배열은 어떻게 되는가?

> [!QUIZ]
> **M5. 포인터 + 배열 + `static` 지역변수 · 확인 6** — 정답 보기. 답을 먼저 적거나 코드를 작성한 뒤 해설과 비교하세요.

> [!ANSWER]
> **정답 보기**
>
> ### (a) 일반 지역변수 `int m = 1`
> 
> 매번 `fun()`이 호출될 때 `m`이 다시 1로 생성됩니다.
> 
> ```text
> s = {5, 5, 6, 7, 8}
> ```
> 
> ### (b) `static int m = 1`
> 
> `m`의 값이 함수 호출 사이에 유지되어 `1 → 0 → 1 → 0 ...`으로 바뀝니다.
> 
> ```text
> s = {5, 6, 8, 10, 12}
> ```
> 
> ### 기억할 부분
> 
> ```cpp
> *(p + k)
> ```
> 
> 와
> 
> ```cpp
> p[k]
> ```
> 
> 는 같은 원소를 가리킵니다.

## 시험 직전 체크리스트

- [ ] `for`, `if`, `%`를 보고 출력값을 손으로 추적할 수 있다.
- [ ] 값 전달과 참조 전달의 차이를 안다.
- [ ] 참조 변수는 선언 즉시 초기화해야 한다.
- [ ] 재귀식을 반복식으로 바꿀 수 있다.
- [ ] `a[i] == *(a + i)`를 이해한다.
- [ ] 배열 합/내적을 `for`문으로 구현할 수 있다.
- [ ] 일반 지역변수와 `static` 지역변수의 생명주기 차이를 안다.
