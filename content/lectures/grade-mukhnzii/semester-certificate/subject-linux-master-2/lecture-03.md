리눅스마스터 2급의 세 번째 학습 영역입니다. **윈도우 → 인터넷 활용 → 응용분야** 순서로 학습합니다.

## 1장 윈도우

- 리눅스 X-윈도우
- 리눅스 X-윈도우 매니저
- X-윈도우 원격 접속 보안 제어
- X-윈도우 응용 프로그램의 종류와 특징

## 2장 인터넷 활용

- 네트워크 통신망의 이해
- 네트워크 장비
- OSI 7계층
- IP 주소 체계 및 서브네팅
- 메일 서비스
- 파일 전송 서비스
- 도메인 서비스
- 원격 서비스
- 파일 공유 서비스
- 네트워크 인터페이스

## 3장 응용분야

- 리눅스 클러스터링
- 임베디드 리눅스
- 리눅스 가상화
- 클라우드 서비스 모델
- 5대 핵심 플랫폼
- 빅데이터
- 하둡
- 리눅스 기반 임베디드 및 특화 시스템
