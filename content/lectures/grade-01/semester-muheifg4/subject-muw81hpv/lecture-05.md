# 오버로딩·포인터·동적 메모리

**슬라이드:** Lecture 6 (6주차) · Function Overloading, Pointers and Pointer Arithmetic, The Heap

포인터는 C++에서 처음 배우는 사람이 가장 많이 막히는 곳입니다. 하지만 규칙은 몇 개 안 됩니다. 이 강의는 **변수가 메모리 어디에 사는가**에서 출발해, 그림을 그리며 한 줄씩 따라가는 방식으로 설명합니다. 2026 일정에서 포인터는 **중간고사 범위**입니다.

이 강의는 **이 페이지 하나만 읽어도** 이해되도록 썼습니다. 앞 강의에서 배운 것(참조, 배열, C 문자열)이 필요한 곳에는 "먼저 짚고 가기" 상자로 다시 설명하고, 모든 예제는 `#include`부터 `main`까지 **그대로 복사해 컴파일할 수 있는 완전한 프로그램**과 g++로 실제 실행한 **실행 결과**를 함께 보여 줍니다. "문법 모양"이라고 표시한 짧은 조각은 문법의 생김새만 보여 주는 것이고, 바로 앞이나 뒤에 그 문법을 쓰는 완전한 프로그램이 있습니다.

---

## 학습 흐름

```text
함수 오버로딩 → 모호한 호출 → 기본 인수
        ↓
메모리와 주소 → 포인터 선언 · 주소 연산자 & · 역참조 * → 포인터 자료형
        ↓
포인터와 함수(call by reference) → const 포인터
        ↓
배열과 포인터 → 포인터 연산 → 포인터 배열 · 이중 포인터 → C 문자열
        ↓
sizeof와 힙 → malloc/calloc/free → new/delete
```

> [!EXAM]
> 포인터 문제는 **그림을 그리면** 틀리지 않습니다. 변수마다 상자를 그리고, 포인터는 화살표로 표시한 뒤 한 줄씩 상자 값과 화살표를 갱신하세요.

## 1. 함수 오버로딩

**함수 오버로딩**은 이름이 같은 함수를 여러 개 두고 매개변수의 **자료형이나 개수**로 구분하는 것입니다. 어느 함수를 쓸지는 **컴파일할 때** 인수를 보고 정합니다.

> [!NOTE]
> **비유로 이해하기 — 같은 이름의 직원 두 명**
>
> 회사에 "김민수"가 두 명 있다고 합시다. 한 명은 **숫자 서류(double)** 담당, 한 명은 **정수 서류(int)** 담당입니다. 손님이 "김민수 씨요!" 하고 서류를 내밀면 안내 데스크(컴파일러)가 **들고 온 서류의 종류**를 보고 어느 김민수에게 보낼지 정합니다.
> - 서류만 보고는 누구에게 보낼지 애매하면 안내 데스크가 아예 접수를 거부합니다 → **모호한 호출 = 컴파일 오류**.
> - 안내 데스크는 손님이 **무엇을 돌려받을지**(반환형)는 보지 않습니다. 그래서 반환형만 다른 두 함수는 구분할 수 없습니다.
>
> 비유의 한계: 실제로는 사람이 아니라 컴파일러가 **컴파일할 때 한 번** 정하고, 실행 중에는 다시 고르지 않습니다.

슬라이드의 예입니다. 어느 버전이 불렸는지 보이도록 출력 한 줄씩을 넣었습니다.

```cpp
#include <iostream>
using namespace std;

double max(double num1, double num2) {
    cout << "[double 버전] ";
    return num1 > num2 ? num1 : num2;
}

int max(int num1, int num2) {
    cout << "[int 버전] ";
    return num1 > num2 ? num1 : num2;
}

int main() {
    double d = max(2.5, 3.0);   // 인수가 double 두 개 → double 버전
    cout << d << '\n';

    int i = max(2, 3);          // 인수가 int 두 개 → int 버전
    cout << i << '\n';
}
```

```text
실행 결과
[double 버전] 3
[int 버전] 3
```

**모호한 호출(ambiguous invocation)** — 맞을 수 있는 함수가 둘 이상인데 어느 쪽이 더 잘 맞는지 컴파일러가 정하지 못하면 **컴파일 오류**입니다.

**컴파일 오류 예시**

```cpp
#include <iostream>
// 이 예제만 using namespace std;를 쓰지 않습니다(아래 TRAP 참고).

double max(int num1, double num2) { return num1 > num2 ? num1 : num2; }
double max(double num1, int num2) { return num1 > num2 ? num1 : num2; }

int main() {
    double d = max(4.0, 5.0);   // 어느 쪽이든 인수 하나를 double→int로 바꿔야 함
    std::cout << d << '\n';
}
```

```text
g++ 오류 (핵심 줄)
error: call of overloaded 'max(double, double)' is ambiguous
note: candidate: 'double max(int, double)'
note: candidate: 'double max(double, int)'
```

두 후보 모두 인수 하나씩을 `double → int`로 바꿔야 해서 우열이 없습니다. **캐스트**로 어느 쪽인지 정해 주면 풀립니다.

```cpp
#include <iostream>
using namespace std;

double max(int num1, double num2) {
    cout << "[max(int, double)] ";
    return num1 > num2 ? num1 : num2;
}
double max(double num1, int num2) {
    cout << "[max(double, int)] ";
    return num1 > num2 ? num1 : num2;
}

int main() {
    double d = max((int)4.0, 5.0);   // 첫 인수를 int로 캐스트 → 첫 번째 버전으로 확정
    cout << d << '\n';
    d = max(4, 5.0);                 // 처음부터 int, double → 정확히 일치
    cout << d << '\n';
}
```

```text
실행 결과
[max(int, double)] 5
[max(int, double)] 5
```

> [!TRAP]
> 위 오류 예시에 `using namespace std;`를 넣으면 **오류가 나지 않고 5가 출력됩니다.** 표준 라이브러리에도 `std::max`라는 함수(템플릿)가 있어서, `max(4.0, 5.0)`에 **정확히 맞는** `std::max`가 끼어들기 때문입니다. 시험에서는 "직접 만든 두 `max`만 있다"고 보고 모호한 호출로 답하면 되지만, 실제로 코드를 짤 때는 직접 만드는 함수 이름을 `max`, `min`, `swap`처럼 표준 함수와 겹치게 짓지 않는 편이 안전합니다.

> [!TRAP]
> **반환형만 다른** 함수는 오버로딩이 아닙니다(`int f(int)`와 `double f(int)`는 컴파일 오류). 구분 기준은 매개변수 목록뿐입니다.

### 오버로딩

**이름이 같고 매개변수 목록(개수 또는 자료형)이 다른** 함수를 여러 개 만들 수 있습니다. 컴파일러가 인수의 자료형을 보고 가장 잘 맞는 함수를 고릅니다. 순서는 대략 **① 정확히 일치 → ② 승격(작은 자료형을 같은 계열의 큰 자료형으로: `float → double`, `bool`·`char → int`) → ③ 그 밖의 변환**입니다. 같은 단계에 후보가 둘 이상이면 모호합니다.

```cpp
#include <iostream>
using namespace std;

void f(int)    { cout << "int "; }      // 매개변수를 안에서 쓰지 않으므로 이름 생략
void f(double) { cout << "double "; }
void f(char)   { cout << "char "; }

int add(int a, int b = 10, int c = 100) { return a + b + c; }

int main() {
    f(3); f(3.0); f('a'); f(3.0f); f(true);
    cout << '\n' << add(1) << ' ' << add(1, 2) << ' ' << add(1, 2, 3) << '\n';
    // f(3L);   // 이 줄을 살리면 컴파일 오류(모호한 호출)
}
```

```text
실행 결과
int double char double int 
111 103 6
```

| 호출 | 선택 | 이유 |
| --- | --- | --- |
| `f(3)` | `f(int)` | 정확히 일치 |
| `f(3.0)` | `f(double)` | 정확히 일치 |
| `f('a')` | `f(char)` | 정확히 일치 |
| `f(3.0f)` | `f(double)` | float → double 승격 |
| `f(true)` | `f(int)` | bool → int 승격 |
| `f(3L)` | **컴파일 오류** | long → int / double / char가 모두 "변환"이라 우열이 없음(모호) |

`f(3L)` 줄을 살리면 g++는 다음처럼 거부합니다.

**컴파일 오류 예시**

```cpp
#include <iostream>
using namespace std;

void f(int)    { cout << "int "; }
void f(double) { cout << "double "; }
void f(char)   { cout << "char "; }

int main() {
    f(3L);   // long: int로도, double로도, char로도 "변환"이 필요
}
```

```text
g++ 오류 (핵심 줄)
error: call of overloaded 'f(long int)' is ambiguous
```

반환형만 다른 함수를 두 개 만들면 이렇게 됩니다.

**컴파일 오류 예시**

```cpp
#include <iostream>
using namespace std;

int    g() { return 1; }
double g() { return 2.5; }   // 반환형만 다름

int main() {
    cout << g() << '\n';
}
```

```text
g++ 오류 (핵심 줄)
error: ambiguating new declaration of 'double g()'
```

> [!TRAP]
> - **반환형만 다른** 함수는 오버로딩이 아닙니다. `int g();`와 `double g();`는 함께 둘 수 없습니다(컴파일 오류).
> - 매개변수 **이름**만 다른 것도 같은 함수입니다.

### 기본 인수

인수를 생략하면 기본값을 씁니다. 기본값은 **오른쪽 매개변수부터** 채워야 합니다.

> [!NOTE]
> **비유로 이해하기 — 세트 메뉴의 기본 음료**
>
> "햄버거 세트 주세요"라고만 하면 음료는 콜라, 사이드는 감자튀김(기본값)이 나옵니다. "음료는 사이다로"라고 말하면 그것만 바뀝니다. 다만 주문은 **앞에서부터 순서대로** 말해야 해서, 음료를 건너뛰고 사이드만 바꿀 수는 없습니다. 그래서 기본값은 **뒤(오른쪽)부터** 붙입니다.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b = 10, int c = 100) {   // b, c는 생략 가능
    return a + b + c;
}

int main() {
    cout << add(1) << '\n';         // add(1, 10, 100)
    cout << add(1, 2) << '\n';      // add(1, 2, 100)
    cout << add(1, 2, 3) << '\n';   // 기본값을 쓰지 않음
}
```

```text
실행 결과
111
103
6
```

**컴파일 오류 예시** — 기본값 뒤에 기본값 없는 매개변수

```cpp
int bad(int a = 1, int b) { return a + b; }   // 기본값 뒤에 기본값 없는 매개변수

int main() {
    return bad(2);
}
```

```text
g++ 오류 (핵심 줄)
error: default argument missing for parameter 2 of 'int bad(int, int)'
```

> [!TRAP]
> 오버로딩과 기본 인수가 겹치면 모호해집니다. `void k(int);`와 `void k(int, int = 0);`이 함께 있으면 `k(5)`는 둘 다 맞아서 **컴파일 오류**입니다.

**컴파일 오류 예시**

```cpp
#include <iostream>
using namespace std;

void k(int a)            { cout << "k(int)\n"; }
void k(int a, int b = 0) { cout << "k(int, int)\n"; }

int main() {
    k(5);   // 두 함수 모두 k(5)로 부를 수 있음
}
```

```text
g++ 오류 (핵심 줄)
error: call of overloaded 'k(int)' is ambiguous
```

> [!QUIZ]
> 위의 `f` 세 개와 `add`가 있을 때 출력을 쓰시오. 컴파일 오류인 호출이 있으면 표시하시오.
>
> ```cpp
> f(3); f(3.0); f('a'); f(3.0f); f(true);
> cout << '\n' << add(1) << ' ' << add(1, 2) << ' ' << add(1, 2, 3);
> f(3L);
> ```

> [!ANSWER]
> ```text
> int double char double int 
> 111 103 6
> ```
>
> `f(3L)`은 세 함수 모두 변환이 필요해 **모호한 호출**이므로 컴파일 오류입니다. 이 줄을 지워야 위 출력이 나옵니다. (위 "오버로딩" 절의 완전한 프로그램이 바로 이 줄을 주석 처리한 버전입니다.)

## 2. 변수는 메모리에 산다

> [!NOTE]
> **먼저 짚고 가기 — 메모리, 바이트, 주소**
>
> - 컴퓨터의 메모리(RAM)는 **1바이트짜리 칸이 아주 길게 한 줄로 늘어선 것**입니다. 칸마다 0번, 1번, 2번 … 하는 **번호**가 붙어 있고, 이 번호를 **주소**(address)라고 부릅니다. 주소는 보통 `0x7ffc…` 같은 16진수로 표시합니다.
> - 변수 하나는 칸을 여러 개 차지할 수 있습니다. `int`는 보통 4칸(4바이트), `double`은 8칸, `char`는 1칸입니다. 변수의 주소는 그 변수가 차지한 **첫 칸의 번호**입니다.
> - 변수를 선언하면 컴파일러가 칸을 잡아 주고 우리는 **이름**으로 그 칸을 씁니다. 지금까지는 이름만 썼고, 이번 강의에서 처음으로 번호, 곧 **주소**를 직접 다룹니다.

[![주소 1004에 있는 int x와 주소 1016에 있는 포인터 p를 메모리 표로 그리고 p가 x를 가리키며 *p = 5로 x가 5가 되는 그림](/materials/diagrams/cpp-05-pointer-memory.svg)](/materials/diagrams/cpp-05-pointer-memory.svg)

*그림 5-1 · 포인터는 주소를 담는 변수 — 누르면 원본 크기로 열린다.*


`int n = 42;`라고 쓰면 컴파일러는 메모리 어딘가에 `int` 하나가 들어갈 칸(보통 4바이트)을 잡고, 그 칸에 이름 `n`을 붙이고, 42를 넣습니다. 이 칸에는 번호, 곧 **주소**가 있습니다.

```text
주소      0x1000   0x1004   0x1008
         ┌───────┬───────┬───────┐
         │  42   │   7   │   …   │
         └───────┴───────┴───────┘
이름        n        m
```

- 우리는 평소에 **이름**(`n`)으로 칸을 씁니다.
- 포인터는 이름 대신 **주소**(`0x1000`)로 칸을 다루는 방법입니다.
- 실제 주소 값은 실행할 때마다 다르고 시험에도 나오지 않습니다. 중요한 것은 "**어느 칸을 가리키는가**"라는 관계입니다. 그래서 그림에서는 주소 숫자 대신 **화살표**를 씁니다.

> [!NOTE]
> **비유로 이해하기 — 아파트와 호수**
>
> 메모리는 아주 긴 아파트 복도이고, 칸 하나하나가 집입니다. 집마다 **호수**(주소)가 있고, 변수 이름은 문패입니다. 우리는 "철수네 집"(이름)이라고 부를 수도 있고 "1004호"(주소)라고 부를 수도 있습니다. 둘 다 같은 집입니다.

`&n`이라고 쓰면 `n`의 주소를 얻을 수 있습니다. 주소를 그대로 출력해 보는 완전한 프로그램입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 42;
    int m = 7;
    cout << "n의 값: " << n << ", n의 크기: " << sizeof(n) << "바이트\n";
    cout << "n의 주소: " << &n << '\n';
    cout << "m의 주소: " << &m << '\n';
}
```

```text
실행 결과 (한 번 실행한 예 — 주소 값은 실행할 때마다, 컴퓨터마다 다름)
n의 값: 42, n의 크기: 4바이트
n의 주소: 0x7ffc2e1247c0
m의 주소: 0x7ffc2e1247c4
```

첫 줄은 항상 같지만, 두 주소는 실행할 때마다 바뀝니다. 이 실행에서는 `m`이 `n` 바로 4바이트 뒤에 놓였지만, 서로 다른 변수가 어떤 순서로 놓일지는 **보장되지 않습니다**(그래서 따로 선언한 변수끼리 주소 계산을 하면 안 됩니다).

> [!NOTE]
> 왜 굳이 주소로 다룰까요? ① 함수가 **호출한 쪽의 변수를 직접 바꾸게** 하려고(4절), ② **배열을 훑으려고**(5절), ③ 실행 중에 크기가 정해지는 **메모리를 빌리려고**(7절)입니다. 이 세 가지가 포인터를 배우는 이유의 전부입니다.

## 3. 주소와 포인터

**포인터**(pointer)는 **주소를 값으로 저장하는 변수**입니다. `int`가 정수를 담는 상자라면, `int*`는 "어떤 `int`가 있는 곳의 주소"를 담는 상자입니다.

> [!NOTE]
> **비유로 이해하기 — 주소가 적힌 쪽지**
>
> 포인터는 **집 주소가 적힌 쪽지**입니다.
> - `p = &n` → 쪽지에 `n`네 집 주소를 적는다.
> - `*p` → 쪽지에 적힌 주소로 **찾아가서 문을 연다**(그 집 안의 값).
> - `*p = 100` → 그 집에 찾아가 안의 물건을 100으로 바꾼다. 집 주인(`n`)이 보기에도 물건이 바뀌어 있습니다.
> - `nullptr` → 아무 주소도 적혀 있지 않은 **빈 쪽지**. 빈 쪽지를 들고 찾아갈 수는 없습니다.
> - 초기화하지 않은 포인터 → 누가 **아무렇게나 휘갈긴 쪽지**. 그 주소로 찾아가면 남의 집 문을 열게 됩니다.
>
> 비유의 한계: 쪽지 자체도 메모리 어딘가에 놓인 변수라서 **쪽지에도 주소가 있습니다**. 이 점이 7-4절의 이중 포인터로 이어집니다.

### 3-1. 기호 세 개만 기억하기

| 기호 | 어디에 쓰나 | 뜻 | 읽는 법 |
| --- | --- | --- | --- |
| `&x` | 식 안 | 변수 `x`의 **주소** | "x의 주소" |
| `int* p` | 선언 | `p`는 `int`의 주소를 저장하는 **포인터** | "int를 가리키는 포인터 p" |
| `*p` | 식 안 | `p`가 가리키는 곳의 **값**(역참조) | "p가 가리키는 값" |
| `int& r` | 선언 | 참조(별명). 주소 연산자와 **다른** 뜻 | "int 참조 r" (04강, 아래 상자) |

> [!NOTE]
> **먼저 짚고 가기 — 참조(reference)는 별명**
>
> 04강에서 배운 참조를 짧게 다시 봅니다. `int& r = x;`는 **새 칸을 만들지 않고** 이미 있는 칸 `x`에 이름 `r`을 하나 더 붙입니다. 그 뒤로 `r`을 바꾸면 `x`가 바뀝니다. 참조는 선언할 때 **반드시** 대상을 정해야 하고, 한번 정하면 다른 변수의 별명으로 바꿀 수 없습니다.
>
> 비유: 참조는 **별명**("철수" = "반장"), 포인터는 **주소 쪽지**입니다. 별명은 그 사람 자체를 부르는 말이라 따로 들고 다닐 물건이 아니지만, 쪽지는 그 자체가 하나의 물건(변수)이라 고쳐 쓰거나(`p = &m`) 비워 둘(`nullptr`) 수 있습니다.

> [!TRAP]
> `*`와 `&`는 **선언에 쓰일 때**와 **식에 쓰일 때** 뜻이 다릅니다.
> - 선언 `int* p` → "p는 포인터다" / 식 `*p` → "p가 가리키는 값"
> - 선언 `int& r = x` → "r은 x의 별명이다" / 식 `&x` → "x의 주소"
>
> 줄 맨 앞에 **자료형이 있으면 선언**, 없으면 식이라고 구분하면 됩니다.

### 3-2. 첫 포인터 프로그램

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 42;
    int* p = &n;          // ① p에 n의 주소를 넣는다 → p는 n을 가리킨다

    cout << n << '\n';    // n을 이름으로 읽기
    cout << *p << '\n';   // p가 가리키는 칸(n)의 값

    *p = 100;             // ② p가 가리키는 칸(n)에 100을 넣는다
    cout << n << '\n';    // n을 직접 건드리지 않았는데 바뀌었다
    cout << (p == &n) << '\n';   // p에 든 값 = n의 주소인가? → 1(참)
}
```

```text
실행 결과
42
42
100
1
```

```text
① 직후:   p ──▶ [ n : 42 ]
② 직후:   p ──▶ [ n : 100 ]
```

`*p = 100`은 "p 상자에 100을 넣어라"가 아니라 "**p가 가리키는 상자**에 100을 넣어라"입니다. 그래서 `n`이 바뀝니다. `bool` 값은 `cout`으로 출력하면 참이 `1`, 거짓이 `0`으로 나옵니다.

### 3-3. 포인터를 만들 때 지켜야 할 규칙

- 포인터 자료형은 가리킬 값의 자료형과 맞아야 합니다. `int n; double* d = &n;`은 **컴파일 오류**입니다.
- 아무것도 가리키지 않을 때는 `nullptr`로 초기화합니다.
- 초기화하지 않은 포인터나 `nullptr`을 **역참조하면 UB**(정의되지 않은 동작, 보통 비정상 종료)입니다.
- `int* p = 5;`처럼 정수를 바로 넣는 것은 **컴파일 오류**입니다. 포인터에는 주소만 들어갑니다.

`nullptr` 확인 습관을 보여 주는 완전한 프로그램입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = nullptr;     // 아직 가리킬 곳이 없다 → 빈 쪽지

    if (p != nullptr) {   // 쓰기 전에 확인하는 습관
        cout << *p << '\n';
    } else {
        cout << "p는 아무것도 가리키지 않습니다\n";
    }

    int n = 5;
    p = &n;               // 이제 n을 가리킨다
    if (p != nullptr) {
        cout << "*p = " << *p << '\n';
    }
}
```

```text
실행 결과
p는 아무것도 가리키지 않습니다
*p = 5
```

**컴파일 오류 예시** — 포인터에 정수를 바로 넣기

```cpp
int main() {
    int* p = 5;   // 정수를 바로 주소 자리에
}
```

```text
g++ 오류 (핵심 줄)
error: invalid conversion from 'int' to 'int*' [-fpermissive]
```

> [!TRAP]
> `int* p, q;`에서 `q`는 포인터가 아니라 **그냥 int**입니다. `*`는 자료형이 아니라 **변수 이름마다** 붙습니다. 두 개 다 포인터로 만들려면 `int *p, *q;`라고 씁니다.

**컴파일 오류 예시** — `q`가 포인터인 줄 알고 주소를 넣으면

```cpp
int main() {
    int x = 1;
    int* p, q;   // p는 int*, q는 그냥 int
    p = &x;
    q = &x;      // int 변수에 주소를 넣으려 함
}
```

```text
g++ 오류 (핵심 줄)
error: invalid conversion from 'int*' to 'int' [-fpermissive]
```

올바르게 쓴 완전한 프로그램입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 1, y = 2;
    int *p, *q;          // 변수마다 *를 붙여야 둘 다 포인터
    p = &x;
    q = &y;
    cout << *p << ' ' << *q << '\n';
}
```

```text
실행 결과
1 2
```

> [!QUIZ]
> `int* p, q;`라고 선언했을 때 `q`의 자료형은?
>
> **A.** `int*`
>
> **B.** `int`
>
> **C.** `int&`
>
> **D.** 선언 자체가 컴파일 오류

> [!ANSWER]
> B. `*`는 바로 뒤의 변수 이름 `p`에만 붙습니다. 그래서 `p`는 `int*`, `q`는 그냥 `int`입니다. 둘 다 포인터로 만들려면 `int *p, *q;`라고 씁니다.

### 3-4. 값 복사와 주소 복사 — 가장 중요한 구분

| 문장 | 무엇을 복사하나 | 그림에서 바뀌는 것 |
| --- | --- | --- |
| `*p = *q;` | q가 가리키는 **값**을 p가 가리키는 칸으로 | **상자 안의 숫자** |
| `p = q;` | q에 적힌 **주소**를 p로 | **화살표 방향** |

> [!NOTE]
> **비유로 이해하기 — 물건 옮기기 vs 쪽지 베끼기**
>
> - `*p = *q` → q 쪽지의 집에 가서 물건을 보고, **같은 물건을 p 쪽지의 집에 가져다 놓는다.** 집(변수)의 내용이 바뀝니다.
> - `p = q` → q 쪽지에 적힌 주소를 **p 쪽지에 그대로 베껴 적는다.** 어느 집의 물건도 바뀌지 않고, 이제 두 쪽지가 같은 집을 가리킬 뿐입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1, b = 2;
    int* p = &a;
    int* q = &b;

    *p = *q;   // 값 복사: a = b
    cout << "*p = *q 후: a=" << a << " b=" << b << '\n';

    p = q;     // 주소 복사: 이제 p도 b를 가리킨다(화살표만 이동)
    cout << "p = q 후:   a=" << a << " b=" << b << " (p == q) " << (p == q) << '\n';

    *p = 9;    // p가 가리키는 b에 9
    cout << "*p = 9 후:  a=" << a << " b=" << b << '\n';
}
```

```text
실행 결과
*p = *q 후: a=2 b=2
p = q 후:   a=2 b=2 (p == q) 1
*p = 9 후:  a=2 b=9
```

```text
처음:        p ──▶ [a:1]      q ──▶ [b:2]
*p = *q:     p ──▶ [a:2]      q ──▶ [b:2]
p = q:       [a:2]            p ──┐
                              q ──┴▶ [b:2]
*p = 9:      [a:2]            p, q ──▶ [b:9]
```

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> int a = 10, b = 20;
> int* p = &a;
> int* q = &b;
> *p = *q + 5;
> p = q;
> *p = 7;
> cout << a << ' ' << b << ' ' << *p << ' ' << *q << ' ' << (p == q);
> ```

> [!ANSWER]
> ```text
> 25 7 7 7 1
> ```
>
> | 문장 | 의미 | a | b | p가 가리킴 |
> | --- | --- | ---: | ---: | --- |
> | `*p = *q + 5` | a = b + 5 | 25 | 20 | a |
> | `p = q` | 주소 복사 (화살표 이동) | 25 | 20 | **b** |
> | `*p = 7` | b = 7 | 25 | 7 | b |
>
> `p = q`는 **값이 아니라 주소**를 복사합니다. 이후 `*p`와 `*q`는 같은 변수입니다. `p == q`는 두 주소가 같은지 비교하므로 1(참)입니다. (`#include <iostream>`, `using namespace std;`, `int main() { … }`로 감싸 실행하면 정확히 이 줄이 출력됩니다.)

> [!QUIZ]
> 다음 선언에서 (1) `p[0] == n`의 참·거짓, (2) `p = &k;`의 대입 가능 여부를 쓰고, (3) 배열 `arr`의 `arr[i]`를 포인터 연산으로 쓰시오.
>
> ```cpp
> int n = 3;
> int& k = n;
> int* p = &n;
> ```

> [!ANSWER]
> (1) **참**. `p[0]`은 `*(p + 0)` = `*p` = `n`입니다. (2) **가능**. `k`는 `n`의 별명이므로 `&k`는 `&n`과 같은 주소입니다. (3) `*(arr + i)`.
>
> 세 가지를 모두 확인하는 완전한 프로그램입니다(`*(arr + i)`는 5절에서 자세히 다룹니다).
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> int main() {
>     int n = 3;
>     int& k = n;          // k는 n의 별명(참조)
>     int* p = &n;         // p는 n의 주소를 담은 포인터
>
>     cout << (p[0] == n) << '\n';   // (1)
>     p = &k;                        // (2) 별명의 주소 = 원본의 주소
>     cout << (p == &n) << '\n';
>
>     int arr[3] = {10, 20, 30};
>     int i = 2;
>     cout << arr[i] << ' ' << *(arr + i) << '\n';   // (3)
> }
> ```
>
> ```text
> 실행 결과
> 1
> 1
> 30 30
> ```

> [!CHECK]
> 스스로 확인: `int x = 5; int* p = &x; *p = *p * 2;` 뒤에 `x`는? → **10**. `*p * 2`의 앞 `*`는 역참조, 가운데 `*`는 곱셈입니다.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> int main() {
>     int x = 5;
>     int* p = &x;
>     *p = *p * 2;   // 앞 *: 역참조, 가운데 *: 곱셈
>     cout << x << '\n';
> }
> ```
>
> ```text
> 실행 결과
> 10
> ```

**포인터 자료형은 맞아야 한다** (Lecture 6 슬라이드 16)

`int*`는 "4바이트를 정수로 읽어라", `double*`는 "8바이트를 실수로 읽어라"는 뜻까지 담고 있습니다. 그래서 다른 자료형의 주소는 넣을 수 없습니다.

**컴파일 오류 예시**

```cpp
int main() {
    int n = 5;      double x = 5.0;
    int *ptr1;      double *ptr2;
    ptr1 = &n;      // OK
    ptr2 = &n;      // double 포인터에 int의 주소
    ptr1 = &x;      // int 포인터에 double의 주소
}
```

```text
g++ 오류 (핵심 줄)
error: cannot convert 'int*' to 'double*' in assignment
error: cannot convert 'double*' to 'int*' in assignment
```

**초기화하지 않은 포인터** — `int *p; *p = 1;`은 아무 주소에나 1을 씁니다. 운이 나쁘면 "segmentation fault"로 죽고, 더 나쁘면 다른 변수를 조용히 망가뜨려 **틀린 결과로 계속 실행**됩니다. 이것은 정의되지 않은 동작(UB)이라 "정해진 실행 결과"가 없으므로 여기서는 출력을 보여 주지 않습니다. 해결책은 하나입니다. 포인터는 **선언할 때 바로** 실제 변수의 주소나 `nullptr`로 초기화하세요.

## 4. 포인터와 함수

> [!NOTE]
> **먼저 짚고 가기 — 함수는 인수를 복사해서 받는다**
>
> `void addOne(int x)`를 `addOne(a)`로 부르면, `a`의 **값이 복사되어** 새 변수 `x`가 만들어집니다. 함수 안에서 `x`를 아무리 바꿔도 `a`는 그대로입니다. 이것을 **값에 의한 전달**(call by value)이라고 합니다. 함수가 호출한 쪽 변수를 바꾸게 하려면 ① 그 변수의 **주소**를 넘기거나(포인터, 이 절), ② 그 변수의 **별명**을 넘깁니다(참조 매개변수 `int& x`, 04강).

[![값으로 받은 swap은 복사본만 바꿔 n과 m이 그대로이고 포인터로 받은 swap은 원본 n과 m을 바꾸는 비교 그림](/materials/diagrams/cpp-05-swap.svg)](/materials/diagrams/cpp-05-swap.svg)

*그림 5-2 · swap(n, m)과 swap(&n, &m) — 누르면 원본 크기로 열린다.*

함수 매개변수를 포인터로 선언하면, 호출할 때 **변수의 주소**를 넘겨 함수가 호출한 쪽 변수를 바꿀 수 있습니다. 슬라이드는 이것을 **call by reference**라고 부릅니다(04강의 참조 매개변수와 같은 효과).

> [!NOTE]
> **비유로 이해하기 — 사진 복사본 vs 집 주소**
>
> - 값으로 넘기기 = 내 방 **사진을 복사해서** 친구에게 준다. 친구가 사진에 낙서를 해도 내 방은 그대로입니다.
> - 주소로 넘기기 = 친구에게 **내 집 주소를 알려 준다.** 친구가 그 주소로 와서 가구를 옮기면 내 방이 실제로 바뀝니다. 택배 기사에게 "여기에 넣어 주세요" 하고 주소를 주면 결과물을 내 집에서 받을 수 있는 것처럼, 결과를 여러 개 돌려받을 때도 이 방법을 씁니다.

슬라이드의 `fun`입니다. 결과 두 개(합과 곱)를 주소로 돌려받습니다.

```cpp
#include <iostream>
using namespace std;

void fun(int a, int b, int *p1, int *p2) {
    *p1 = a + b;      // p1이 가리키는 칸(sum)에 합을 저장
    *p2 = a * b;      // p2가 가리키는 칸(product)에 곱을 저장
}

int main() {
    int x = 3, y = 5, sum, product;
    fun(x, y, &sum, &product);   // 결과를 넣을 칸의 주소를 넘긴다
    cout << "sum = " << sum << ", product = " << product << '\n';
}
```

```text
실행 결과
sum = 8, product = 15
```

### 4-1. 왜 필요한가: 함수는 원래 복사본을 받는다

C++ 함수는 기본적으로 인수를 **복사해서** 받습니다. 그래서 함수 안에서 매개변수를 바꿔도 호출한 쪽 변수는 그대로입니다. 호출한 쪽 변수를 바꾸고 싶으면 **주소를 넘기거나**(포인터), **별명을 넘깁니다**(참조). 세 방법을 한 프로그램에서 비교합니다.

```cpp
#include <iostream>
using namespace std;

void addOne(int x)   { x = x + 1; }      // x는 복사본
void addOneP(int* x) { *x = *x + 1; }    // 주소를 받아 그 칸을 바꿈
void addOneR(int& x) { x = x + 1; }      // 별명이라 원본 그 자체

int main() {
    int a = 5;
    addOne(a);
    cout << "addOne(a) 후:   " << a << '\n';   // 복사본만 바뀜
    addOneP(&a);
    cout << "addOneP(&a) 후: " << a << '\n';   // 주소를 넘김
    addOneR(a);
    cout << "addOneR(a) 후:  " << a << '\n';   // 이름 그대로 넘김(참조)
}
```

```text
실행 결과
addOne(a) 후:   5
addOneP(&a) 후: 6
addOneR(a) 후:  7
```

### 4-2. swap 네 가지 — 시험의 단골

문법 모양(네 함수의 머리와 몸통만):

```cpp
void s1(int a, int b)   { int t = a; a = b; b = t; }        // 복사본 교환
void s2(int* a, int* b) { int t = *a; *a = *b; *b = t; }    // 가리키는 값 교환
void s3(int* a, int* b) { int* t = a; a = b; b = t; }       // 지역 포인터만 교환
void s4(int& a, int& b) { int t = a; a = b; b = t; }        // 원본 교환
```

`s3`이 함정입니다. 포인터도 **값으로 전달**되므로, 함수 안의 `a`, `b`는 호출할 때 넘겨준 주소를 **복사한 쪽지**입니다. 쪽지끼리 바꿔 들어도 원래 상자 안의 값은 그대로입니다.

```text
s3 안:   a(쪽지 복사본) ──▶ [x]        b(쪽지 복사본) ──▶ [y]
교환 후:  a ──▶ [y]   b ──▶ [x]      ← 쪽지만 바뀜, x와 y의 값은 그대로
```

> [!NOTE]
> **비유로 이해하기 — s3은 "쪽지 복사본 맞바꾸기"**
>
> 친구에게 우리 두 집 주소를 적은 쪽지를 **복사해서** 줬습니다. 친구가 자기 손에 든 쪽지 두 장을 왼손·오른손 바꿔 들어도, 두 집의 가구는 하나도 움직이지 않습니다. 가구를 바꾸려면 쪽지에 적힌 집에 **찾아가서**(`*a`, `*b`) 옮겨야 합니다 — 그게 `s2`입니다.

| 구분 | 포인터 매개변수 | 참조 매개변수 |
| --- | --- | --- |
| 선언 | `void f(int* p)` | `void f(int& r)` |
| 호출 | `f(&x)` | `f(x)` |
| 안에서 사용 | `*p` | `r` |
| "없음" 표현 | `nullptr` 가능 | 불가(반드시 대상이 있음) |
| 다른 대상으로 바꾸기 | 가능 | 불가 |

> [!QUIZ]
> `int x = 1, y = 2;`에서 시작해 아래를 **차례로** 실행할 때 각 호출 뒤의 `x y`를 쓰시오.
>
> ```cpp
> s1(x, y);   s2(&x, &y);   s3(&x, &y);   s4(x, y);
> ```

> [!ANSWER]
> | 호출 | x y | 이유 |
> | --- | --- | --- |
> | `s1(x, y)` | 1 2 | 값 복사본만 교환 |
> | `s2(&x, &y)` | 2 1 | `*a`, `*b`로 원본 교환 |
> | `s3(&x, &y)` | 2 1 | 포인터 변수(복사본)끼리만 교환, 값은 그대로 |
> | `s4(x, y)` | 1 2 | 참조로 원본 교환 |
>
> `s3`이 함정입니다. 포인터도 **값으로 전달**되므로 함수 안에서 `a = b`를 해도 호출한 쪽에는 영향이 없습니다.
>
> 네 함수를 모두 넣은 완전한 프로그램과 실제 출력입니다.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> void s1(int a, int b)   { int t = a; a = b; b = t; }        // 복사본 교환
> void s2(int* a, int* b) { int t = *a; *a = *b; *b = t; }    // 가리키는 값 교환
> void s3(int* a, int* b) { int* t = a; a = b; b = t; }       // 지역 포인터만 교환
> void s4(int& a, int& b) { int t = a; a = b; b = t; }        // 원본 교환
>
> int main() {
>     int x = 1, y = 2;
>     s1(x, y);   cout << "s1 후: " << x << ' ' << y << '\n';
>     s2(&x, &y); cout << "s2 후: " << x << ' ' << y << '\n';
>     s3(&x, &y); cout << "s3 후: " << x << ' ' << y << '\n';
>     s4(x, y);   cout << "s4 후: " << x << ' ' << y << '\n';
> }
> ```
>
> ```text
> 실행 결과
> s1 후: 1 2
> s2 후: 2 1
> s3 후: 2 1
> s4 후: 1 2
> ```

### 4-3. 포인터 매개변수로 여러 결과 돌려주기

`return`은 값을 하나만 돌려줍니다. 결과가 둘 이상이면 **결과를 넣을 칸의 주소**를 받아서 채웁니다. 매개변수 `const int a[]`는 "배열을 받되 읽기만 한다"는 뜻입니다(배열을 함수에 넘기는 원리는 5절).

```cpp
#include <iostream>
using namespace std;

void minmax(const int a[], int n, int* mn, int* mx) {
    *mn = *mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < *mn) *mn = a[i];
        if (a[i] > *mx) *mx = a[i];
    }
}

int main() {
    int arr[4] = {4, -2, 9, 0};
    int lo, hi;
    minmax(arr, 4, &lo, &hi);     // lo, hi의 주소를 넘김
    cout << "최솟값 " << lo << ", 최댓값 " << hi << '\n';
}
```

```text
실행 결과
최솟값 -2, 최댓값 9
```

`&lo`, `&hi`를 넘겼으므로 함수 안의 `*mn`, `*mx`는 곧 `lo`, `hi`입니다.

### 4-4. const와 포인터

포인터에는 고정할 수 있는 것이 **두 가지** 있습니다.

1. **가리키는 값** — 이 포인터로 값을 바꾸지 못하게
2. **포인터 자체(화살표)** — 다른 곳을 가리키지 못하게

규칙은 하나입니다. `const`가 `*`의 **왼쪽**에 있으면 **값**을, **오른쪽**에 있으면 **포인터 자체**를 고정합니다.

```text
const int *  p      → const가 * 왼쪽  → 값 고정     ("상수를 가리키는 포인터")
      int *  const p → const가 * 오른쪽 → 화살표 고정 ("상수 포인터")
```

> [!NOTE]
> **비유로 이해하기 — 열람 전용 출입증과 전용 열쇠**
>
> - `const int* p` = **열람 전용 출입증**. 들어가서 **보기만** 할 수 있고 물건은 못 바꿉니다. 대신 출입증을 다른 집 것으로 바꿔 받을 수는 있습니다(`p = &m` 가능).
> - `int* const p` = **그 집 전용 열쇠**. 다른 집에는 못 쓰지만(`p = &m` 불가), 그 집 안의 물건은 바꿀 수 있습니다(`*p = 5` 가능).
> - `const int* const p` = 그 집 전용 **열람** 출입증. 둘 다 안 됩니다.
>
> 비유의 한계: 열람 전용 출입증으로 못 바꾸는 것이지, 집 주인(변수 이름)은 여전히 자기 물건을 바꿀 수 있습니다(아래 `n = 2`).

| 선언 | `*p = 5` (값 변경) | `p = &m` (가리키는 곳 변경) | 읽는 법 |
| --- | :---: | :---: | --- |
| `int* p` | O | O | 보통 포인터 |
| `const int* p` (= `int const* p`) | **X** | O | 상수를 가리키는 포인터 |
| `int* const p` | O | **X** | 상수 포인터 (선언할 때 초기화 필수) |
| `const int* const p` | **X** | **X** | 둘 다 고정 |

> [!NOTE]
> **뒤에서부터 읽기** 요령: `int* const p` → "p는 const인 포인터, int를 가리키는". `const int* p` → "p는 포인터, const int를 가리키는". 영어 선언문을 오른쪽에서 왼쪽으로 읽으면 뜻이 맞아떨어집니다.

`const int*`가 **const가 아닌 변수**를 가리키는 것은 괜찮습니다. "이 포인터로는 바꾸지 않겠다"는 약속일 뿐, 변수 자체는 이름으로 바꿀 수 있습니다. 반대로 `const` 변수를 **보통 포인터**로 가리키면 그 포인터로 상수를 바꿀 수 있게 되므로 컴파일 오류입니다. 허용되는 동작만 모은 완전한 프로그램입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 1, m = 2;

    const int* r = &n;     // 상수를 가리키는 포인터: r로는 값을 못 바꿈
    n = 2;                 // 이름으로는 바꿀 수 있음
    r = &m;                // 가리키는 곳은 바꿀 수 있음
    cout << "*r = " << *r << '\n';

    int* const s = &n;     // 상수 포인터: 화살표 고정(선언 때 초기화 필수)
    *s = 50;               // 가리키는 값은 바꿀 수 있음
    cout << "n = " << n << '\n';

    const int c = 9;
    const int* p5 = &c;    // const 변수는 const int*로 가리킨다
    cout << "*p5 = " << *p5 << '\n';
}
```

```text
실행 결과
*r = 2
n = 50
*p5 = 9
```

> [!QUIZ]
> 컴파일 오류가 나는 줄을 모두 고르시오.
>
> ```cpp
> int n = 1, m = 2;
> const int* p1 = &n;
> *p1 = 5;               // (1)
> p1 = &m;               // (2)
> int* const p2 = &n;
> *p2 = 5;               // (3)
> p2 = &m;               // (4)
> const int* const p3 = &n;
> *p3 = 5;               // (5)
> p3 = &m;               // (6)
> const int c = 9;
> int* p4 = &c;          // (7)
> const int* p5 = &c;    // (8)
> ```

> [!ANSWER]
> 오류: **(1), (4), (5), (6), (7)**. `const int*`는 값을, `int* const`는 주소를 바꿀 수 없습니다. `const int*`가 `n`처럼 const가 아닌 변수를 가리키는 것은 괜찮습니다(그 포인터로 바꿀 수 없을 뿐).
>
> 위 코드를 `int main() { … }`에 넣어 g++로 컴파일하면 정확히 다섯 줄에서 오류가 납니다(핵심 줄만, 괄호 번호는 해당 문항).
>
> ```text
> g++ 오류 (핵심 줄)
> (1) error: assignment of read-only location '* p1'
> (4) error: assignment of read-only variable 'p2'
> (5) error: assignment of read-only location '*(const int*)p3'
> (6) error: assignment of read-only variable 'p3'
> (7) error: invalid conversion from 'const int*' to 'int*' [-fpermissive]
> ```
>
> "read-only location"은 **가리키는 값**이, "read-only variable"은 **포인터 자체**가 고정되었다는 뜻입니다.

## 5. 배열과 포인터

> [!NOTE]
> **먼저 짚고 가기 — 배열 (04강 복습)**
>
> - `int a[5];`는 `int` 칸 **다섯 개를 메모리에 빈틈없이 붙여서** 잡습니다. 첨자는 0부터: `a[0]` … `a[4]`. `a[5]`는 범위 밖이고, 범위 밖 접근은 UB입니다.
> - `int a[5] = {1, 2, 3, 4, 5};`처럼 중괄호로 초기화합니다. 배열끼리 `=`로 대입할 수는 없습니다.
> - 배열을 함수에 넘기면(`print(a, 5)`) 함수 안에서 바꾼 내용이 **원본에 남습니다.** 배열은 복사되지 않기 때문인데, 그 이유가 바로 이 절의 내용입니다. 함수는 배열의 크기를 모르므로 크기를 따로 넘깁니다.

[![int 배열 a 다섯 칸 위에서 ptr이 a 0을, ptr+2가 a 2를, ptr+4가 a 4를 가리키는 그림](/materials/diagrams/cpp-05-pointer-arithmetic.svg)](/materials/diagrams/cpp-05-pointer-arithmetic.svg)

*그림 5-3 · 포인터 연산은 원소 단위 — 누르면 원본 크기로 열린다.*

슬라이드: “**배열 이름은 기본적으로 const 포인터**(주소가 고정된 포인터)다.” 그래서 `int *x; int a[10]; x = a;`는 OK이고 `x[2]`는 `a[2]`와 같습니다. 배열을 함수에 넘기면 원본이 바뀌었던 이유가 이것입니다 — 배열 전체가 아니라 **시작 주소**가 넘어갔기 때문입니다.

> [!NOTE]
> **비유로 이해하기 — 기차와 칸 번호**
>
> 배열은 칸이 붙어 있는 **기차**입니다. 배열 이름 `a`는 "**1호차(맨 앞 칸)가 서 있는 위치**"입니다. 기차 전체를 다른 역으로 옮겨 주는 대신 "1호차 위치"만 알려 주면, 받은 사람은 거기서부터 칸을 세어 몇 호차든 찾아갈 수 있습니다. 함수에 배열을 넘기는 것이 바로 이것이라, 함수는 **원래 기차**에 직접 손을 댑니다.

슬라이드의 `print_array` 두 모양을 담은 완전한 프로그램입니다.

```cpp
#include <iostream>
using namespace std;

void print_array(int a[], int len) {          // 배열 모양으로 받기
    for (int i = 0; i < len; i++) cout << i << " " << a[i] << '\n';
}
void print_array_ptr(int *a, int len) {       // 포인터 모양으로 받기 (같은 뜻)
    for (int i = 0; i < len; i++) cout << i << " " << *a++ << '\n';
}

int main() {
    int x[3] = {7, 8, 9};
    int *p;
    p = x;                         // 배열 이름 = 첫 원소의 주소 → 포인터에 대입 OK
    cout << "p[2] = " << p[2] << '\n';
    print_array(x, 3);
    print_array_ptr(x, 3);
}
```

```text
실행 결과
p[2] = 9
0 7
1 8
2 9
0 7
1 8
2 9
```

> [!TRAP]
> 슬라이드에서는 두 함수를 같은 이름 `print_array`로 나란히 보여 주지만, 한 프로그램에 둘 다 넣으면 **컴파일 오류**입니다. 매개변수 `int a[]`는 실제로 `int* a`와 **완전히 같은 자료형**이라, 1절의 오버로딩 규칙으로 보면 "같은 함수를 두 번 정의한 것"이 되기 때문입니다. 그래서 위 프로그램에서는 두 번째 이름을 `print_array_ptr`로 바꿨습니다.

**컴파일 오류 예시**

```cpp
void print_array(int a[], int len) { }
void print_array(int *a, int len) { }   // 위와 같은 함수로 취급

int main() { }
```

```text
g++ 오류 (핵심 줄)
error: redefinition of 'void print_array(int*, int)'
```

### 5-1. 배열 이름은 첫 원소의 주소처럼 쓰인다

배열 `int a[5]`는 메모리에 칸 다섯 개가 **붙어서** 놓입니다. 배열 이름 `a`는 대부분의 식에서 **첫 원소의 주소**(`&a[0]`)로 바뀝니다.

```text
          a[0]  a[1]  a[2]  a[3]  a[4]
         ┌─────┬─────┬─────┬─────┬─────┐
         │  1  │  2  │  3  │  4  │  5  │
         └─────┴─────┴─────┴─────┴─────┘
          ▲     ▲           ▲
          a    a+1         a+3
```

그래서 다음 세 줄은 모두 같은 규칙입니다.

```text
a[i]  ==  *(a + i)        &a[i]  ==  a + i        p[i]  ==  *(p + i)
```

대괄호 `a[i]`는 사실 "**a에서 i칸 간 곳의 값**"을 줄여 쓴 것입니다.

### 5-2. 포인터 연산: +1은 "한 칸"

`p + 1`은 주소를 1바이트가 아니라 **원소 하나만큼**(int면 4바이트) 이동합니다. 자료형을 알기 때문에 컴파일러가 알아서 칸 크기를 곱해 줍니다.

> [!NOTE]
> **비유로 이해하기 — "옆집"은 1미터 옆이 아니다**
>
> 아파트에서 "옆집으로 가라"는 1미터 옆이 아니라 **집 한 채 폭만큼** 옆입니다. `p + 1`도 마찬가지로 1바이트가 아니라 **원소 한 개 크기만큼** 옆입니다(`int*`면 4바이트, `double*`면 8바이트).
>
> 비유의 한계: 포인터 연산은 **한 배열(한 기차) 안에서만** 의미가 있습니다. 따로 선언한 변수끼리는 옆집이라는 보장이 없습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {1, 2, 3, 4, 5};
    int* p = a;            // p는 a[0]을 가리킴

    cout << *p << '\n';        // a[0]
    cout << *(p + 2) << '\n';  // 두 칸 뒤 = a[2]
    p++;                       // 이제 a[1]을 가리킴
    cout << *p << '\n';
    cout << p - a << '\n';     // 같은 배열 안 두 포인터의 차이 = 칸 수
    cout << (a + 3 == &a[3]) << ' ' << a[3] << ' ' << *(a + 3) << '\n';
}
```

```text
실행 결과
1
3
2
1
1 4 4
```

- 같은 배열 안의 두 포인터를 빼면 **원소 개수 차이**가 나옵니다.
- 배열 범위를 벗어난 칸을 역참조하면 UB입니다.

### 5-3. 배열 이름과 포인터 변수는 같지 않다

| 비교 | 배열 `int a[5]` | 포인터 `int* p = a` |
| --- | --- | --- |
| `sizeof` | 20 (원소 5개 × 4바이트) | 8 (64비트 환경의 주소 크기) |
| `a = p;`, `a++` | **컴파일 오류** (배열 이름은 대입·증가 불가) | `p++` 가능 |
| 함수 매개변수 `int a[]` | 실제로는 `int* a`와 같음 | |

> [!NOTE]
> 배열 이름은 "그 자리에 고정된 이름표"이고, 포인터는 "옮길 수 있는 쪽지"라고 생각하세요. 이름표는 떼어서 다른 데 붙일 수 없지만(`a++` 불가), 쪽지는 다른 번호로 고쳐 쓸 수 있습니다(`p++` 가능). 함수에 배열을 넘기면 주소만 넘어가므로 함수 안에서 `sizeof`로 배열 크기를 구할 수 없고, 그래서 크기 `n`을 따로 넘깁니다.

### 5-4. `*p++`와 `(*p)++` (우선순위)

후위 `++`가 단항 `*`보다 먼저 묶입니다. 괄호가 없으면 **포인터가 움직이고**, 괄호로 `(*p)`를 묶어야 **값이 바뀝니다**.

| 식 | 묶음 | 하는 일 | 식의 값 |
| --- | --- | --- | --- |
| `*p++` | `*(p++)` | **포인터**를 다음 칸으로, 값은 이동 전 칸 | 이동 전 원소 |
| `(*p)++` | | 가리키는 **값**을 1 증가 | 증가 전 값 |
| `*++p` | `*(++p)` | 포인터를 먼저 이동 | 이동 후 원소 |
| `++*p` | `++(*p)` | 값을 먼저 증가 | 증가 후 값 |

> [!NOTE]
> 외우는 요령: **`++`가 `p` 바로 옆에 붙으면 포인터가 움직이고, `*p`에 붙으면 값이 바뀐다.** 앞에 붙으면(전위) 바뀐 뒤의 것을, 뒤에 붙으면(후위) 바뀌기 전의 것을 식의 값으로 씁니다.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> int arr[] = {10, 20, 30, 40};
> int* p = arr;
> cout << *p++ << ' ';
> cout << (*p)++ << ' ';
> cout << *++p << ' ';
> cout << ++*p << ' ';
> cout << *(p + 1) << ' ' << p[-1] << ' ' << p - arr << '\n';
> for (int v : arr) cout << v << ' ';
> ```

> [!ANSWER]
> ```text
> 10 20 30 31 40 21 2
> 10 21 31 40 
> ```
>
> | 식 | 출력 | p 위치 | 배열 |
> | --- | ---: | ---: | --- |
> | `*p++` | 10 | 1 | 10 20 30 40 |
> | `(*p)++` | 20 | 1 | 10 **21** 30 40 |
> | `*++p` | 30 | 2 | |
> | `++*p` | 31 | 2 | 10 21 **31** 40 |
> | `*(p + 1)`, `p[-1]`, `p - arr` | 40, 21, 2 | 2 | |
>
> `p[-1]`은 `*(p - 1)`, 곧 `p`가 가리키는 칸의 **한 칸 앞**입니다. 배열 안이므로 문제없습니다. (`#include <iostream>`, `using namespace std;`, `int main() { … }`로 감싸 g++로 실행해 확인한 출력입니다.)

> [!QUIZ]
> `int a[5] = {1, 2, 3, 4, 5}; int* p = a;`일 때 출력과 오류를 판정하시오. (64비트 환경)
>
> ```cpp
> cout << sizeof(a) << ' ' << sizeof(p) << ' ' << *(a + 2) << ' '
>      << *(p + 4) << ' ' << (a + 2 == &a[2]) << '\n';
> a = p;      // (가)
> a++;        // (나)
> p++;        // (다)
> ```

> [!ANSWER]
> 출력: `20 8 3 5 1`. (가)와 (나)는 **컴파일 오류**(배열 이름은 대입·증가할 수 없음), (다)는 정상입니다.
>
> (가)·(나)를 지운 완전한 프로그램과, 두 줄을 남겼을 때의 g++ 오류입니다.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> int main() {
>     int a[5] = {1, 2, 3, 4, 5};
>     int* p = a;
>     cout << sizeof(a) << ' ' << sizeof(p) << ' ' << *(a + 2) << ' '
>          << *(p + 4) << ' ' << (a + 2 == &a[2]) << '\n';
>     // a = p;      // (가) 컴파일 오류
>     // a++;        // (나) 컴파일 오류
>     p++;           // (다) OK
>     cout << *p << '\n';
> }
> ```
>
> ```text
> 실행 결과
> 20 8 3 5 1
> 2
> ```
>
> ```text
> g++ 오류 (가)·(나)를 살렸을 때 핵심 줄
> (가) error: incompatible types in assignment of 'int*' to 'int [5]'
> (나) error: lvalue required as increment operand
> ```

### 5-5. 포인터로 배열 훑기

`for`의 인덱스 대신 포인터를 한 칸씩 옮기며 배열을 훑을 수 있습니다. 2차원 배열도 메모리에 한 줄로 있으므로 `int* p = &m[0][0];`이면 `*(p + i * 열수 + j)`가 `m[i][j]`입니다. `int m[2][3]`에서 `*(p + 4)`는 `m[1][1]`입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {3, 1, 4, 1, 5};
    int sum = 0;
    for (int* p = a; p < a + 5; p++) {   // a+5는 마지막 칸 "다음" 위치(끝 표시)
        sum += *p;
    }
    cout << sum << '\n';

    int m[2][3] = {{0, 1, 2}, {4, 5, 6}};
    int* q = &m[0][0];                    // 2차원 배열도 메모리에는 한 줄
    cout << *(q + 4) << ' ' << *(q + 1 * 3 + 1) << ' ' << m[1][1] << '\n';
}
```

```text
실행 결과
14
5 5 5
```

```text
m[0][0] m[0][1] m[0][2] m[1][0] m[1][1] m[1][2]
  p+0     p+1     p+2     p+3     p+4     p+5
```

`a + 5`는 "마지막 칸 바로 다음"을 가리키는 끝 표시입니다. 이 주소와 **비교**하는 것은 허용되지만, `*(a + 5)`처럼 **역참조**하면 범위 밖 접근(UB)입니다.

**포인터 배열과 이중 포인터** (Lecture 6 슬라이드 32–34)

`int* x[2];`는 "**int 포인터 두 개**를 담는 배열"입니다. 각 칸에 서로 다른 배열의 시작 주소를 넣을 수 있습니다.

> [!NOTE]
> **비유로 이해하기 — 쪽지를 모아 둔 수첩**
>
> 포인터 배열은 **주소 쪽지를 여러 장 꽂아 둔 수첩**입니다. `x[1]`은 수첩 두 번째 장에 적힌 주소(배열 `b`의 1호차 위치)이고, `*(x[1] + 1)`은 그 주소에서 한 칸 더 간 곳의 값입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[] = {0, 1, 2};
    int b[] = {4, 5, 6};
    int* x[2];            // int 포인터 두 개짜리 배열
    x[0] = a;  x[1] = b;
    cout << *(x[1] + 1) << ' ' << *(*(x + 1) + 1) << ' ' << x[1][1] << '\n';

    int m[2][3] = {{0, 1, 2}, {4, 5, 6}};
    cout << m[1][1] << ' ' << *(m[1] + 1) << ' ' << *(*(m + 1) + 1) << '\n';
}
```

```text
실행 결과
5 5 5
5 5 5
```

세 식이 모두 같은 원소를 가리킵니다. `*(x + 1)`은 `x[1]`이고, 거기에 `+ 1` 한 뒤 역참조하면 `x[1][1]`입니다. 2차원 배열 `m`도 같은 모양의 식으로 읽을 수 있습니다(`m[1]`은 둘째 행의 시작 주소처럼 쓰입니다).

포인터도 변수이므로 **포인터를 가리키는 포인터**(`int **y`)를 만들 수 있습니다. `*`의 개수가 화살표를 몇 번 따라가는지입니다. 완전한 예제는 7-4절에 있습니다.

## 6. C 문자열

> [!NOTE]
> **먼저 짚고 가기 — C 문자열과 널 문자 (04강 복습)**
>
> C 문자열은 `char` 배열인데, 글자들 뒤에 값이 0인 **널 문자** `'\0'`이 하나 더 들어 있어서 "여기서 끝"을 표시합니다. 그래서 `"abc"`는 실제로 `'a' 'b' 'c' '\0'` **네 칸**입니다. 배열 크기를 따로 들고 다니지 않아도 `'\0'`을 만날 때까지 읽으면 문자열 끝을 알 수 있습니다. 문자열 함수(`strlen`, `strcpy` 등)는 `<cstring>`에 있습니다.

> [!NOTE]
> **비유로 이해하기 — 종점 표지판**
>
> C 문자열은 칸 수를 적어 두지 않은 기차입니다. 대신 맨 끝 칸에 "종점" **표지판**(`'\0'`)이 붙어 있어서, 앞에서부터 한 칸씩 걸어가다 표지판을 만나면 멈춥니다. 표지판을 빠뜨리면 기차 밖 선로까지 계속 걸어가게 됩니다(범위 밖 접근).

C 문자열은 끝에 값이 0인 **널 문자**가 있는 `char` 배열이고, 포인터로 자주 다룹니다. 슬라이드의 두 방법을 완전한 프로그램으로 봅니다.

```cpp
#include <iostream>
using namespace std;

int count_string(const char *s) {     // 방법 1: 하나씩 세기
    int n = 0;
    while (*s) { n++; s++; }          // s가 가리키는 글자가 0('\0')이 아닌 동안
    return n;
}

int count_string2(const char *s) {    // 방법 2: 포인터 뺄셈
    const char *ptr = s;
    while (*ptr) ptr++;               // '\0' 칸까지 이동
    return ptr - s;                   // 같은 배열 안 두 포인터의 차 = 칸 수
}

int main() {
    cout << count_string("RPI") << ' ' << count_string2("RPI") << '\n';
    cout << count_string("") << ' ' << count_string2("Hanyang") << '\n';
}
```

```text
실행 결과
3 3
0 7
```

C 문자열은 `'\0'`(널 문자, 값 0)으로 끝나는 `char` 배열입니다. `"abc"`는 실제로 `'a' 'b' 'c' '\0'` 네 칸입니다.

```text
char s[] = "abc";
┌───┬───┬───┬────┐
│ a │ b │ c │ \0 │   ← sizeof(s) = 4, strlen(s) = 3
└───┴───┴───┴────┘
```

포인터로 `'\0'`을 만날 때까지 순회할 수 있습니다.

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[] = "abc";
    cout << sizeof(s) << ' ' << strlen(s) << '\n';   // '\0' 포함 4칸, 글자 수 3

    const char* t = "abc";
    while (*t) cout << *t++;      // '\0'(0)이면 거짓 → 종료
    cout << '\n';
}
```

```text
실행 결과
4 3
abc
```

`*t++`는 5절에서 본 대로 "지금 글자를 꺼내고 포인터를 다음 글자로"입니다. 문자열 리터럴 `"abc"`는 바꿀 수 없는 상수이므로 포인터로 가리킬 때는 `const char*`를 씁니다.

| 함수 | 역할 | 주의 |
| --- | --- | --- |
| `strlen(s)` | `'\0'` 앞까지의 문자 수 | `sizeof`(배열 전체 크기)와 다름 |
| `strcpy(dst, src)` | 복사 | `dst`가 충분히 커야 함 |
| `strcat(dst, src)` | 뒤에 이어 붙이기 | `dst`가 충분히 커야 함 |
| `strcmp(a, b)` | 같으면 0, a가 사전순으로 앞이면 음수, 뒤면 양수 | 대문자(65~)가 소문자(97~)보다 앞 |

> [!TRAP]
> - 문자열은 `==`로 비교하지 않습니다. `char` 배열끼리 `==`는 **주소**를 비교합니다. `strcmp(a, b) == 0`을 쓰세요.
> - 문자 배열에 `name = "Kim";`처럼 대입할 수 없습니다(배열 대입 불가). `strcpy(name, "Kim");`을 씁니다. 빈 문자열은 `strcpy(name, "");` 또는 `name[0] = '\0';`.
> - `cin >> name`은 공백 전까지만 읽습니다. 한 줄 전체는 `cin.getline(name, 크기)`.

위 함정 두 가지를 직접 확인하는 완전한 프로그램입니다.

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char x[10] = "hi";
    char y[10] = "hi";
    cout << (x == y) << '\n';               // 두 배열의 주소 비교 → 다른 배열이므로 0
    cout << (strcmp(x, y) == 0) << '\n';    // 내용 비교 → 1

    char name[10];
    // name = "Kim";                        // 컴파일 오류: 배열에는 대입 불가
    strcpy(name, "Kim");                    // 내용 복사
    cout << name << ' ' << strlen(name) << '\n';
    name[0] = '\0';                         // 빈 문자열로 만들기
    cout << "[" << name << "] " << strlen(name) << '\n';
}
```

```text
실행 결과
0
1
Kim 3
[] 0
```

내용이 똑같은 `"hi"`인데도 `x == y`는 0입니다. 서로 다른 두 배열의 **주소**를 비교했기 때문입니다. g++도 `-Wall`에서 `warning: comparison between two arrays`라고 경고해 줍니다. 주석 처리한 `name = "Kim";`을 살리면 다음 오류가 납니다.

```text
g++ 오류 (핵심 줄)
error: incompatible types in assignment of 'const char [4]' to 'char [10]'
```

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> char a[20] = "Hello";
> char b[] = "World";
> cout << strlen(a) << ' ' << sizeof(a) << ' ' << sizeof(b) << ' ';
> strcat(a, b);
> cout << a << ' ' << strlen(a) << ' ';
> cout << (strcmp("abc", "abd") < 0) << ' ' << strcmp("abc", "abc") << ' '
>      << (strcmp("b", "a") > 0) << ' ' << (strcmp("Zoo", "apple") < 0) << '\n';
> ```

> [!ANSWER]
> ```text
> 5 20 6 HelloWorld 10 1 0 1 1
> ```
>
> `sizeof(a)`는 선언한 크기 20, `sizeof(b)`는 `"World"` 다섯 글자 + `'\0'` = 6입니다. `"Zoo" < "apple"`인 이유: `'Z'`(90)가 `'a'`(97)보다 작기 때문입니다. (`#include <iostream>`, `#include <cstring>`, `using namespace std;`, `int main() { … }`로 감싸 실행한 출력입니다.)

## 7. 힙과 동적 메모리

[![스택의 지역 포인터 변수가 힙에 new로 빌린 블록을 가리키고 주소를 잃은 블록은 돌려줄 수 없는 누수가 되는 그림](/materials/diagrams/cpp-05-stack-heap.svg)](/materials/diagrams/cpp-05-stack-heap.svg)

*그림 5-4 · 스택과 힙 — 누르면 원본 크기로 열린다.*

**sizeof** — 자료형(또는 변수)이 차지하는 바이트 수를 알려 줍니다: `std::cout << sizeof(int);` → 보통 4.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(char) << ' ' << sizeof(int) << ' ' << sizeof(double) << ' '
         << sizeof(int*) << '\n';
    int x[10];
    cout << sizeof(x) << ' ' << sizeof(x) / sizeof(x[0]) << '\n';   // 배열 전체, 원소 개수
}
```

```text
실행 결과 (64비트 리눅스, g++)
1 4 8 8
40 10
```

`char`는 언제나 1이고, 나머지는 환경에 따라 다를 수 있습니다. 주소(포인터)는 64비트 환경에서 8바이트입니다.

**힙**(heap)은 **실행 중에** 메모리를 빌릴 수 있는 특별한 영역입니다. 지금까지 배열은 선언할 때 크기를 정해야 했지만(`x[10]`), 힙을 쓰면 **실행 중에야 아는 크기**의 배열을 만들 수 있습니다.

> [!NOTE]
> **비유로 이해하기 — 책상(스택)과 창고 대여(힙)**
>
> - **스택** = 내 **책상 위**. 함수가 시작되면 지역 변수를 책상에 펼치고, 함수(블록)가 끝나면 **자동으로 싹 치웁니다.** 편하지만 책상 크기는 미리 정해져 있고, 자리를 뜨면 남지 않습니다.
> - **힙** = **창고 대여**. `new`(또는 `malloc`)로 필요한 크기만큼 창고를 빌리면 **창고 위치(주소)가 적힌 영수증**을 받습니다. 창고는 내가 **직접 반납(`delete`/`free`)할 때까지** 계속 남아 있습니다.
> - **메모리 누수** = 빌린 창고를 반납하지 않고 영수증(주소)까지 잃어버림. 아무도 그 창고를 쓸 수 없게 됩니다.
> - **댕글링 포인터** = 이미 반납한 창고의 영수증을 들고 다시 들어가려 함. 그 창고는 이미 다른 사람 물건이 들어 있을 수 있습니다.
> - **이중 해제** = 이미 반납한 창고를 또 반납하려 함.
>
> 비유의 한계: 프로그램이 완전히 끝나면 운영체제가 창고를 모두 회수합니다. 문제는 프로그램이 **오래 실행되는 동안** 반납 안 된 창고가 쌓이는 것입니다.

**C 방식 (`<stdlib.h>`)** — 다음 학기 C 코드에서도 만납니다.

| 함수 | 하는 일 |
| --- | --- |
| `calloc(n, el_size)` | 원소 n개 × el_size 바이트의 연속 공간 (0으로 채움) |
| `malloc(size)` | size 바이트 공간 |
| `free(p)` | 빌린 공간 반납 (크기는 C가 내부에 기억) |

`malloc`·`calloc`은 **`void*`**(자료형이 정해지지 않은 주소)를 돌려주므로 C++에서는 `(int*)`처럼 명시적으로 변환해야 합니다. 빌리기에 실패하면 `NULL`을 돌려줍니다.

```cpp
#include <iostream>
#include <stdlib.h>      // malloc, calloc, free
using namespace std;

int main() {
    int n = 4;           // 실제로는 실행 중에 정해지는 값이라고 생각하자

    int *a = (int*)malloc(n * sizeof(int));   // n칸, 내용은 정해지지 않음
    int *b = (int*)calloc(n, sizeof(int));    // n칸, 모두 0으로 채움
    if (a == NULL || b == NULL) return 1;     // 빌리기 실패 확인

    for (int i = 0; i < n; i++) a[i] = i * 10;   // malloc 공간은 직접 채워서 쓴다

    for (int i = 0; i < n; i++) cout << a[i] << ' ';
    cout << '\n';
    for (int i = 0; i < n; i++) cout << b[i] << ' ';
    cout << '\n';

    free(a);             // 반납 (크기는 C가 내부에 기억)
    free(b);
}
```

```text
실행 결과
0 10 20 30 
0 0 0 0 
```

> [!TRAP]
> C에서는 `void*`가 다른 포인터로 **자동 변환**되지만 C++에서는 **컴파일 오류**입니다. 그래서 `int *p = fun();`(fun이 `void*` 반환)은 C에서는 되고 C++에서는 안 됩니다. C++에서는 아래의 `new`를 씁니다.

**컴파일 오류 예시** — 아래 코드는 C 컴파일러(gcc)로는 통과하지만 C++(g++)로는 오류입니다.

```cpp
#include <stdlib.h>

int main() {
    int *p = malloc(4 * sizeof(int));   // C에서는 OK, C++에서는?
    free(p);
}
```

```text
g++ 오류 (핵심 줄)
error: invalid conversion from 'void*' to 'int*' [-fpermissive]
```

### 7-1. 왜 필요한가

지금까지의 변수는 **컴파일할 때 크기가 정해진** 메모리(스택)에 삽니다. 그래서 `int arr[n];`처럼 실행 중에 입력받은 `n`으로 배열 크기를 정하는 것은 표준 C++에서 허용되지 않습니다(g++는 확장 기능으로 받아 주기도 하지만 표준이 아닙니다). 또 지역 변수는 블록이 끝나면 사라집니다.

`new`는 **실행 중에 필요한 만큼** 메모리를 빌려(힙) 그 **주소**를 돌려줍니다. 빌린 메모리는 **직접 `delete`로 돌려줄 때까지** 남아 있습니다.

```text
스택 (자동)                       힙 (직접 관리)
┌────────────┐                  ┌──────────────────┐
│ arr: 주소 ─┼───────────────▶  │ [ ][ ][ ][ ] (n칸)│
└────────────┘                  └──────────────────┘
블록이 끝나면 arr 변수는 사라짐      delete[] 하기 전까지 남아 있음
```

### 7-2. 쓰는 법

```cpp
#include <iostream>
using namespace std;

int main() {
    int* one = new int(42);        // int 하나를 빌리고 42로 초기화
    cout << *one << '\n';
    delete one;                    // 돌려줌
    one = nullptr;

    int n;
    cin >> n;                      // 크기를 실행 중에 입력받음
    int* arr = new int[n];         // 실행 중에 크기 결정
    for (int i = 0; i < n; i++) arr[i] = (i + 1) * (i + 1);   // 일반 배열처럼 사용
    for (int i = 0; i < n; i++) cout << arr[i] << ' ';
    cout << '\n';
    delete[] arr;                  // 배열은 delete[]
    arr = nullptr;                 // 댕글링 방지
}
```

```text
입력
5
```

```text
실행 결과
42
1 4 9 16 25 
```

`5` 대신 `3`을 입력하면 둘째 줄은 `1 4 9 `가 됩니다. 배열 크기가 **실행 중에** 정해졌다는 뜻입니다.

| 할당 | 해제 | 짝이 틀리면 |
| --- | --- | --- |
| `new T` | `delete p` | UB |
| `new T[n]` | `delete[] p` | UB |

> [!NOTE]
> 도서관 책과 같습니다. `new`로 빌린 책은 `delete`로 반납해야 다른 사람이 쓸 수 있습니다. 반납하지 않고 대출증(주소)을 잃어버리면 그 책은 영영 아무도 못 쓰는데, 이것이 **메모리 누수**입니다. 반납한 책의 번호로 다시 책장을 뒤지면 엉뚱한 책이 나오는데, 이것이 **댕글링 포인터**입니다.

### 7-3. 흔한 사고 네 가지

| 문제 | 상황 |
| --- | --- |
| **메모리 누수** | 해제하지 않은 채 주소를 잃음: `p = new int(1); p = new int(2);` |
| **댕글링 포인터** | 해제한 뒤에도 그 주소를 사용: `delete p; *p = 3;` |
| **이중 해제** | 같은 메모리를 두 번 `delete` (UB). `nullptr`에 대한 `delete`는 안전 |
| **스택 변수 해제** | `int x; delete &x;` (UB). `new`로 받은 것만 해제 |

댕글링 포인터, 이중 해제, 스택 변수 해제는 **UB**라서 "정해진 실행 결과"가 없습니다(멀쩡해 보이다가 나중에 엉뚱한 곳에서 죽기도 합니다). 그래서 아래 프로그램에는 UB가 없는 부분 — 누수가 생기는 순간과 안전한 반납 습관 — 만 넣었습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int* p = new int(1);
    p = new int(2);     // 누수: 1이 든 메모리의 주소를 잃었다(이제 반납할 방법이 없음)
    cout << *p << '\n';

    delete p;           // 2가 든 메모리 반납
    p = nullptr;        // 반납 후 nullptr → 실수로 다시 써도 바로 드러남
    delete p;           // nullptr이므로 아무 일도 안 함(안전)

    if (p == nullptr) cout << "p는 비어 있음\n";
}
```

```text
실행 결과
2
p는 비어 있음
```

출력만 보면 아무 문제가 없어 보입니다. 누수는 **출력에 드러나지 않는다**는 점이 무섭습니다. 1이 든 창고는 프로그램이 끝날 때까지 아무도 반납하지 못한 채 남아 있습니다.

> [!QUIZ]
> 다음 출력을 쓰고, 마지막에 필요한 문장을 쓰시오.
>
> ```cpp
> int n = 4;
> int* d = new int[n];
> for (int i = 0; i < n; i++) d[i] = i * i;
> int* e = d + 1;
> e[1] = 100;
> for (int i = 0; i < n; i++) cout << d[i] << ' ';
> ```

> [!ANSWER]
> `0 1 100 9`. `e`는 `d[1]`을 가리키므로 `e[1]`은 `d[2]`입니다. 마지막에 `delete[] d;`가 필요합니다. `e`를 따로 해제하면 이중 해제가 됩니다.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> int main() {
>     int n = 4;
>     int* d = new int[n];
>     for (int i = 0; i < n; i++) d[i] = i * i;
>     int* e = d + 1;
>     e[1] = 100;
>     for (int i = 0; i < n; i++) cout << d[i] << ' ';
>     cout << '\n';
>     delete[] d;          // 빌린 주소 d로 한 번만 반납
> }
> ```
>
> ```text
> 실행 결과
> 0 1 100 9 
> ```

### 7-4. 이중 포인터

포인터도 변수이므로 주소가 있습니다. **포인터의 주소**를 담는 것이 이중 포인터입니다.

> [!NOTE]
> **비유로 이해하기 — 보물찾기 쪽지**
>
> `pp`는 "**쪽지 p가 있는 서랍의 위치**"가 적힌 쪽지입니다. `*pp`는 서랍을 열어 쪽지 `p`를 꺼내는 것, `**pp`는 꺼낸 쪽지에 적힌 집까지 한 번 더 찾아가는 것입니다. 보물찾기에서 "다음 쪽지는 화분 밑에" → "보물은 책장 위에"처럼 **쪽지를 두 번 따라가는** 셈입니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5;
    int* p = &x;
    int** pp = &p;    // 포인터 p의 주소를 담는다

    cout << **pp << '\n';          // 화살표 두 번 → x
    **pp = 9;                      // x = 9
    cout << x << '\n';
    cout << (*pp == &x) << '\n';   // 화살표 한 번 → p (= x의 주소)

    int y = 7;
    *pp = &y;                      // p 자체를 바꿈: 이제 p는 y를 가리킴
    cout << *p << '\n';
}
```

```text
실행 결과
5
9
1
7
```

```text
pp ──▶ [ p ] ──▶ [ x : 9 ]
*pp  = p           (첫 번째 화살표를 따라감)
**pp = x           (두 번째 화살표까지 따라감)
```

`*`의 개수가 **화살표를 몇 번 따라가는지**입니다. 마지막 두 줄처럼 `*pp`에 대입하면 **쪽지 `p` 자체를 고쳐 쓰게** 됩니다. 함수가 호출한 쪽의 **포인터 변수**를 바꾸게 하고 싶을 때 이중 포인터를 넘기는 이유가 이것입니다(4-2절 `s3`의 함정을 피하는 방법).

### 7-5. 실무에서는: vector와 스마트 포인터

실무에서는 직접 `new[]`/`delete[]`를 쓰는 일을 줄입니다. `vector<int> v(n);`을 쓰면 크기를 실행 중에 정할 수 있고 메모리가 **자동으로** 해제됩니다. 객체 하나를 동적으로 관리할 때는 `unique_ptr<int> p = make_unique<int>(42);`처럼 스마트 포인터를 씁니다(`<memory>`). 이 둘은 소멸할 때 알아서 `delete`해 주므로 누수가 생기지 않습니다.

> [!NOTE]
> **비유로 이해하기 — 자동 반납 렌탈**
>
> `vector`와 `unique_ptr`은 **기간이 끝나면 알아서 반납해 주는 렌탈 서비스**입니다. 변수가 블록 끝에서 사라질 때(책상을 치울 때) 빌린 창고도 자동으로 반납되므로 영수증을 잃어버릴 일이 없습니다.

```cpp
#include <iostream>
#include <vector>
#include <memory>
using namespace std;

int main() {
    int n = 3;
    vector<int> v(n);                       // 실행 중 크기 결정, 자동 해제
    for (int i = 0; i < n; i++) v[i] = i + 1;
    v.push_back(4);                          // 크기도 늘릴 수 있음
    for (int x : v) cout << x << ' ';
    cout << "(size " << v.size() << ")\n";

    unique_ptr<int> p = make_unique<int>(42);   // new 대신, delete 없이
    cout << *p << '\n';
}                                            // 여기서 v와 p가 알아서 메모리 반납
```

```text
실행 결과
1 2 3 4 (size 4)
42
```

다만 시험에서는 `new`/`delete`의 짝과 사고 유형이 나오므로 7절을 확실히 알아 두세요.

## 핵심 정리

1. 오버로딩은 매개변수 자료형·개수로 구분하고 컴파일할 때 고른다. 모호하면 컴파일 오류, 반환형만 다르면 오버로딩 아님. 기본 인수는 오른쪽부터.
2. `&x`는 주소, `*p`는 가리키는 값. `p = q`는 화살표 이동(쪽지 베끼기), `*p = *q`는 값 복사(물건 옮기기). 포인터 자료형은 가리킬 값과 맞아야 한다.
3. 초기화 안 한 포인터를 역참조하면 segmentation fault 또는 조용한 데이터 손상. 선언할 때 주소나 `nullptr`로 초기화한다.
4. 주소를 넘기면 함수가 호출한 쪽 변수를 바꾼다(결과 여러 개 돌려받기). 포인터 자체도 복사되어 전달된다(`s3` 함정).
5. `const`가 `*` 왼쪽이면 값 고정, 오른쪽이면 포인터 고정.
6. 배열 이름은 주소가 고정된 포인터. `a[i] == *(a + i)`, `p + 1`은 원소 한 칸. 매개변수 `int a[]`는 `int* a`와 같다.
7. C 문자열은 `'\0'`까지. 포인터 뺄셈으로 길이를 구할 수 있다. 비교는 `strcmp`, 복사는 `strcpy`.
8. 힙: C는 malloc/calloc/free, C++은 new/delete와 new[]/delete[]. 짝을 맞추고 해제 후 nullptr. 실무에서는 vector와 unique_ptr.
