# 형 변환과 제어 구조

**슬라이드:** Lecture 3 (3주차) · Control Structures, Expressions, Operators

        ↓

## 1. 자료형이 섞인 식과 형 변환

[![bool char short가 int로 승격되고 int unsigned long long long float double 순서로 넓은 쪽으로 변환되며 double을 int에 넣으면 값이 잘리는 조용한 축소와 명시적 캐스트를 보인 그림](/materials/diagrams/cpp-02-conversion-ladder.svg)](/materials/diagrams/cpp-02-conversion-ladder.svg)

*그림 2-1 · 형 변환 사다리 — 누르면 원본 크기로 열린다.*

**자료형이 섞인 식(mixed-type expression)**은 서로 다른 자료형의 피연산자가 함께 있는 식입니다. 계산 규칙(**usual arithmetic conversions**)은 두 단계입니다.

1. **정수 승격:** `bool`, `char`, `short`는 먼저 `int`가 된다.
2. 그래도 자료형이 다르면 **좁은 쪽을 넓은 쪽으로** 바꾼다:
   `int → unsigned int → long → unsigned long → long long → unsigned long long → float → double`

결과는 **가장 넓은 자료형**이 됩니다. 자동 변환은 **조용히** 일어나므로, 내가 정하고 싶으면 캐스트를 씁니다: `double result = (double)7 / 2; // 3.5`

**조용한 축소(silent narrowing)** — 값을 표현할 수 없는 좁은 자료형으로 넣으면 값이 손실되는데, C++은 많은 경우 경고 없이 진행합니다.

```cpp
uint16_t x = 10000;  uint8_t y = x;   // 10000을 8비트에 → 값 손실 (16)
double d = 3.14;     int n = d;       // 3 (소수 부분 사라짐)
```

컴파일러가 경고하지 않는 경우가 많아 실행 중에야 틀린 값으로 드러나므로 위험합니다.

| 언어 | 섞인 식 | 축소 |
| --- | --- | --- |
| C/C++ | 자동 승격 | **조용히** 축소·확대 |
| Java | 비슷한 승격(작은 형 → int, int+double → double) | 캐스트 없이는 축소 불가 |
| Python | 실행 중 동적 변환(`3 + 4.5` → 7.5) | — |
| Rust | **자동 승격 없음** | 모두 명시적 캐스트 |

### 산술 변환: 더 넓은 쪽으로

서로 다른 자료형을 계산하면 **더 넓은 자료형**으로 맞춘 뒤 계산합니다.

```text
bool, char, short → int (정수 승격)
int  op double    → double
int  op long long → long long
```

### 축소 변환: 정보 손실

넓은 자료형을 좁은 자료형에 넣으면 값이 잘립니다. 실수 → 정수는 **소수 부분을 버립니다(0 쪽으로)**.

```cpp
int n = 3.99;     // 3
int m = -3.99;    // -3  (내림이 아니라 0 쪽으로)
int k{3.99};      // 컴파일 오류: 중괄호 초기화는 축소 변환을 막음
```

### 명시적 변환

```cpp
static_cast<double>(7) / 2   // 3.5  (C++ 방식)
(double)7 / 2                // 3.5  (C 방식)
```

> [!TRAP]
> **변환 시점**이 중요합니다. `double x = 7 / 2;`는 오른쪽이 먼저 **정수 나눗셈**(3)으로 계산된 뒤 `double`에 저장되므로 `3`입니다. `(double)(7 / 2)`도 이미 3이 된 값을 바꾸므로 `3`입니다. 나누기 **전에** 바꿔야 3.5가 됩니다.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> int a = 7, b = 2;
> double x = a / b;
> double y = (double)a / b;
> double z = (double)(a / b);
> int n = 3.99;
> int m = -3.99;
> cout << x << ' ' << y << ' ' << z << ' ' << n << ' ' << m << '\n';
> ```

> [!ANSWER]
> ```text
> 3 3.5 3 3 -3
> ```
>
> `x`와 `z`는 정수 나눗셈 3을 변환한 것이고, `y`만 나누기 전에 `a`를 `double`로 바꿨습니다. `double` 3.0은 `cout`에서 `3`으로 출력됩니다.

### 부동소수점 오차

`float`, `double`은 많은 십진 소수를 정확히 저장하지 못합니다. 그래서 `0.1 + 0.2 == 0.3`은 **거짓**입니다. 실수 비교는 오차 범위를 둡니다.

```cpp
#include <cmath>
bool same = fabs((0.1 + 0.2) - 0.3) < 1e-9;   // true
```

## 2. 논리·증감·복합 대입 연산자와 우선순위

| 연산자 | 뜻 | 참이 되는 때 |
| --- | --- | --- |
| `cond1 && cond2` | 그리고(AND) | **둘 다** 참 |
| `cond1 \|\| cond2` | 또는(OR) | **하나라도** 참 |
| `!cond` | 아니다(NOT, 피연산자 1개인 단항 연산자) | cond가 거짓 |

“이상한” 예: `int x = 5; int y = !x;` → x가 0이 아니므로 참, `!`로 거짓, 정수로는 **0**. (슬라이드에는 1로 적혀 있지만 `!5`는 0입니다 — 컴파일러로 확인한 값.)

**증감 연산자** — `x++`는 **값을 먼저 읽고 나중에 증가**(후위), `++x`는 **먼저 증가하고 읽음**(전위).

```cpp
int x = 5;
cout << x++ << " ";   // 5 출력 후 x = 6
cout << ++x << endl;  // x = 7 후 7 출력
```

> [!TRAP]
> 슬라이드의 “weird examples” — `int b = a++ + ++a;`, `i++ + i++ + i++`, `x+++x+++x+++x` — 는 **한 식에서 같은 변수를 두 번 이상 바꾸므로 결과가 정해지지 않습니다**(C++17 이전 UB, 이후에도 순서 미지정). 시험에서는 “이런 코드는 쓰면 안 된다”가 정답입니다.

**복합 대입** — `foo += 17;`은 `foo = foo + 17;`의 줄임. `-=`, `*=`, `/=`, `%=`도 같습니다.

[![괄호 증감 곱셈나눗셈나머지 덧셈뺄셈 크기비교 같음비교 논리곱 논리합 대입 순으로 우선순위가 낮아지는 사다리](/materials/diagrams/cpp-01-precedence.svg)](/materials/diagrams/cpp-01-precedence.svg)

*그림 2-2 · 연산자 우선순위 사다리 (Lecture 3 Updated Precedence Table) — 누르면 원본 크기로 열린다.*


### 대입과 복합 대입

`=`는 오른쪽 값을 **계산한 뒤** 왼쪽 변수에 저장합니다. 대입식 자체도 값(대입된 값)을 가집니다.

```cpp
x = y = 10;     // 오른쪽부터: y = 10, 그 결과 10을 x에 대입
x += 3;         // x = x + 3
x %= 4;         // x = x % 4
```

### 증감 연산자: 전위와 후위

| 형식 | 식의 값 | 변수 변화 |
| --- | --- | --- |
| `++x` | **증가한 뒤** 값 | +1 |
| `x++` | **증가 전** 값 | +1 |
| `--x` | 감소한 뒤 값 | −1 |
| `x--` | 감소 전 값 | −1 |

> [!TRAP]
> 한 식 안에서 같은 변수를 두 번 이상 바꾸거나, 바꾸면서 동시에 읽으면 **정의되지 않은 동작**입니다. 예: `i++ + ++i`, `a[i] = i++`. 시험에서 "출력은?"이 아니라 "문제점은?"으로 묻습니다.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> int x = 5;
> int a = x++;
> int b = ++x;
> int c = x-- + 10;
> cout << a << ' ' << b << ' ' << c << ' ' << x << '\n';
> ```

> [!ANSWER]
> ```text
> 5 7 17 6
> ```
>
> | 문장 | 식의 값 | 실행 후 x |
> | --- | ---: | ---: |
> | `a = x++` | 5 | 6 |
> | `b = ++x` | 7 | 7 |
> | `c = x-- + 10` | 7 + 10 = 17 | 6 |

### 비교 연산자와 `=` / `==`

비교 결과는 `bool`이고 출력하면 `1` 또는 `0`입니다.

> [!TRAP]
> `if (x = 0)`은 비교가 아니라 **대입**입니다. `x`에 0을 넣고, 대입식의 값 0이 거짓이므로 `if` 본문은 **절대 실행되지 않습니다**. 반대로 `if (x = 5)`는 항상 참입니다. 둘 다 컴파일은 됩니다(논리 오류).

### 논리 연산자와 0/1 변환

- 조건식에서 **0은 거짓, 0이 아닌 모든 값(음수 포함)은 참**입니다.
- `!`는 결과를 `bool`로 뒤집습니다. `!5`는 `0`, `!0`은 `1`, `!(-3)`은 `0`.
- `bool`을 정수로 바꾸면 `true → 1`, `false → 0`. `bool b = -5;`는 `true`.

### 단락 평가 (Short-circuit)

| 식 | 왼쪽이 이것이면 | 오른쪽은 |
| --- | --- | --- |
| `A && B` | 거짓 | **실행하지 않음** (결과 거짓) |
| `A \|\| B` | 참 | **실행하지 않음** (결과 참) |

오른쪽에 `++`, 함수 호출, 나눗셈이 있으면 **실행 여부**에 따라 결과가 달라집니다. 0으로 나누는 것을 막는 가드로도 씁니다: `d != 0 && 10 / d > 2`.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> int x = 0, y = 0;
> bool r1 = (x++ > 0) && (y++ > 0);
> bool r2 = (x++ > 0) || (y++ > 0);
> bool r3 = (x > 5) || (++y);
> cout << r1 << r2 << r3 << ' ' << x << ' ' << y << '\n';
> ```

> [!ANSWER]
> ```text
> 011 2 1
> ```
>
> - `r1`: `x++ > 0`은 0 > 0으로 거짓(x는 1이 됨) → `y++`는 실행 안 됨.
> - `r2`: `x++ > 0`은 1 > 0으로 참(x는 2) → `y++`는 실행 안 됨.
> - `r3`: `x > 5`가 거짓이므로 `++y`를 실행 → y = 1, 0이 아니므로 참.

### 삼항(조건) 연산자 `?:`

```cpp
조건 ? 참일 때 값 : 거짓일 때 값
int max = (a > b) ? a : b;
cout << (n % 2 == 0 ? "even" : "odd");
```

`cout`과 함께 쓸 때는 **괄호로 감싸야** 합니다. `<<`가 `?:`보다 우선순위가 높기 때문입니다.

### 우선순위 표 (위가 먼저 묶임)

| 순위 | 연산자 | 결합 방향 |
| ---: | --- | --- |
| 1 | `( )`, `a[i]`, `f()`, 후위 `x++` `x--` | → |
| 2 | 전위 `++x` `--x`, 단항 `!` `-` `+`, `(type)`, `sizeof` | **←** |
| 3 | `*` `/` `%` | → |
| 4 | `+` `-` | → |
| 5 | `<<` `>>` (cout 출력도 이것) | → |
| 6 | `<` `<=` `>` `>=` | → |
| 7 | `==` `!=` | → |
| 8 | `&&` | → |
| 9 | `\|\|` | → |
| 10 | `? :` | **←** |
| 11 | `=` `+=` `-=` `*=` `/=` `%=` | **←** |

외우는 순서: **단항 → 산술(곱·나눗셈·나머지 → 덧셈·뺄셈) → 비교(크기) → 같음 → AND → OR → 삼항 → 대입**

### 계산하는 방법

1. **단항 연산자**(`!`, `-`, `++`)를 먼저 피연산자에 붙입니다.
2. 우선순위가 높은 연산자부터 **괄호로 묶습니다**.
3. 같은 순위가 이어지면 **왼쪽부터** 묶습니다. (단항, 삼항, 대입만 오른쪽부터)
4. 묶인 괄호를 안쪽부터 계산합니다. 단, `&&`, `||`는 단락 평가로 오른쪽을 건너뛸 수 있습니다.

```text
1 + 2 < 4 && 0 || 3 > 2

① 산술:   (1 + 2) < 4 && 0 || 3 > 2
② 비교:   ((1 + 2) < 4) && 0 || (3 > 2)
③ AND:    (((1 + 2) < 4) && 0) || (3 > 2)
④ OR:     전체
계산:     (1 && 0) || 1  →  0 || 1  →  1
```

```text
!x == 0          →  (!x) == 0        ! 가 == 보다 먼저
-x % 3           →  (-x) % 3         단항 - 가 % 보다 먼저
a % b * 2        →  (a % b) * 2      같은 순위는 왼쪽부터
x < y < z        →  (x < y) < z      0 또는 1과 z를 비교 (수학의 범위 비교가 아님!)
x = (7 * 3 / 4 - 2) * 5 == y   →  x = ((((7*3)/4)-2)*5 == y)   == 가 = 보다 먼저
```

> [!TRAP]
> - `x < y < z`는 "y가 x와 z 사이"가 아닙니다. `x < y && y < z`로 써야 합니다.
> - 우선순위는 **묶는 방법**만 정합니다. `f() + g()`에서 `f`와 `g` 중 무엇이 먼저 **호출**되는지는 정해지지 않습니다.

> [!QUIZ]
> `int a = 10, b = 3;`일 때 각 식의 값을 쓰시오.
>
> | | 식 |
> | --- | --- |
> | (1) | `2 + 3 * 4 % 5` |
> | (2) | `10 - 4 - 3` |
> | (3) | `!0 + 1` |
> | (4) | `5 > 3 == 1` |
> | (5) | `1 + 2 < 4 && 0 \|\| 3 > 2` |
> | (6) | `a % b * 2 + a / b` |
> | (7) | `!a == 0` |
> | (8) | `-2 * -3` |

> [!ANSWER]
> | | 묶는 순서 | 값 |
> | --- | --- | ---: |
> | (1) | `2 + ((3 * 4) % 5)` = 2 + (12 % 5) | **4** |
> | (2) | `(10 - 4) - 3` | **3** |
> | (3) | `(!0) + 1` = 1 + 1 | **2** |
> | (4) | `(5 > 3) == 1` = 1 == 1 | **1** |
> | (5) | `((3 < 4) && 0) \|\| (3 > 2)` = 0 \|\| 1 | **1** |
> | (6) | `((10 % 3) * 2) + (10 / 3)` = 2 + 3 | **5** |
> | (7) | `(!10) == 0` = 0 == 0 | **1** |
> | (8) | `(-2) * (-3)` | **6** |

## 3. 선택 구조: if

**제어 구조**는 두 가지 일을 합니다: **선택**(여러 행동 중 하나 고르기 — `if`, `if/else`, `switch`)과 **반복**(같은 행동 되풀이 — `while`, `for`, `do/while`).

조건은 참·거짓이며, C++에서는 **0이 거짓, 나머지는 참**입니다. 그래서 `if (foo)`는 “foo가 0이 아니면”이라는 뜻입니다.

> [!TRAP]
> `if (grade = 100)`은 비교가 아니라 **대입**입니다. grade에 100을 넣고, 그 값(100)이 0이 아니므로 **항상 참**이 됩니다. 비교는 `==`입니다.

여러 문장을 실행하려면 `{ }`로 묶은 **복합문(블록)**을 씁니다. C++은 공백과 줄 바꿈을 신경 쓰지 않으므로 중괄호를 줄 끝에 두든 다음 줄에 두든 같지만, 읽기 쉽게 한 가지 스타일을 지키세요(요즘 IDE는 자동 정렬 기능이 있습니다).

```cpp
if (score >= 90)      grade = 'A';
else if (score >= 80) grade = 'B';   // 위 조건이 거짓일 때만 검사
else                  grade = 'F';
```

- `else if` 사슬은 **처음 참이 된 분기 하나만** 실행합니다. 그래서 범위가 좁은(높은) 조건을 먼저 씁니다.
- `if`를 여러 개 **따로** 쓰면 각각 독립적으로 검사되어 여러 개가 실행될 수 있습니다.
- 중괄호가 없으면 `if`는 **바로 다음 한 문장**만 지배합니다.

> [!TRAP]
> **매달린 else(dangling else):** `else`는 들여쓰기와 상관없이 **가장 가까운, 짝이 없는 `if`**와 짝을 이룹니다.
>
> ```cpp
> if (a > 3)
>     if (b > 3)
>         cout << "X";
> else                 // 바깥 if처럼 보이지만 안쪽 if의 else
>     cout << "Y";
> ```

> [!QUIZ]
> 각 코드의 출력을 쓰시오.
>
> ```cpp
> // (1)
> int x = 7;
> if (x = 0) cout << "A"; else cout << "B";
> cout << x << '\n';
>
> // (2) a = 5일 때와 a = 1일 때
> int b = 0;
> if (a > 3)
>     if (b > 3)
>         cout << "X";
> else
>     cout << "Y";
> cout << "Z\n";
>
> // (3)
> int s = 95;
> if (s >= 90) cout << "A";
> if (s >= 80) cout << "B";
> else cout << "C";
> cout << '\n';
> ```

> [!ANSWER]
> **(1)** `B0`. `x = 0`은 대입이므로 x는 0이 되고 조건은 거짓입니다.
>
> **(2)** a = 5 → `YZ`, a = 1 → `Z`. `else`는 안쪽 `if (b > 3)`의 짝입니다. a = 1이면 바깥 `if`가 거짓이라 안쪽 if-else 전체를 건너뜁니다.
>
> **(3)** `AB`. 두 `if`는 독립적입니다. 두 번째 `if`의 `else`는 실행되지 않습니다.

## 4. 선택 구조: switch

[![switch 식과 같은 case로 들어가 break까지 실행하고 break가 없으면 다음 case 문장까지 이어지며 맞는 case가 없으면 default로 가는 흐름](/materials/diagrams/cpp-02-switch.svg)](/materials/diagrams/cpp-02-switch.svg)

*그림 2-3 · switch의 실행 흐름 — 누르면 원본 크기로 열린다.*

- 식의 **값**에 따라 여러 경우 중 하나로 갑니다.
- 식의 자료형은 `int`나 `char` 같은 **정수 계열**이어야 하고 `double`은 안 됩니다.
- 각 `case` 끝의 `break`가 없으면 **다음 case로 계속 내려갑니다**(fall-through).

```cpp
switch (정수식) {          // int, char, bool, enum 가능 (double, string 불가)
case 상수1:
    문장;
    break;                 // 없으면 아래 case로 계속 진행 (fall-through)
case 상수2:
case 상수3:                // 여러 값을 같은 처리로 묶기
    문장;
    break;
default:                   // 일치하는 case가 없을 때
    문장;
}
```

> [!EXAM]
> `switch`는 일치하는 `case`로 **점프**한 뒤, `break`를 만날 때까지 **아래로 쭉** 실행합니다. 다른 `case` 레이블을 지나도 멈추지 않습니다. `default`가 중간에 있어도 "일치하는 case가 없을 때 점프할 위치"일 뿐, 그 뒤로 계속 진행합니다.

> [!QUIZ]
> 아래 `sw(n)`에 대해 `sw(2)`, `sw(4)`, `sw(7)`의 출력을 쓰시오. 그리고 `sw2(5)`, `sw2(2)`, `sw2(1)`의 출력을 쓰시오.
>
> ```cpp
> void sw(int n) {
>     switch (n) {
>     case 1: cout << "one ";
>     case 2: cout << "two ";
>     case 3: cout << "three "; break;
>     case 4: cout << "four ";
>     default: cout << "other ";
>     }
> }
>
> void sw2(int n) {
>     switch (n) {
>     default: cout << "D";
>     case 1: cout << "1"; break;
>     case 2: cout << "2";
>     }
> }
> ```

> [!ANSWER]
> | 호출 | 출력 | 이유 |
> | --- | --- | --- |
> | `sw(2)` | `two three ` | case 2부터 실행, case 3의 `break`에서 멈춤 |
> | `sw(4)` | `four other ` | `break`가 없어 default까지 실행 |
> | `sw(7)` | `other ` | 일치하는 case가 없어 default로 |
> | `sw2(5)` | `D1` | default로 점프한 뒤 아래 case 1까지 진행 |
> | `sw2(2)` | `2` | case 2가 마지막이므로 여기서 끝 |
> | `sw2(1)` | `1` | case 1 실행 후 `break` |

## 5. 반복 구조: while · do-while · for

[![while은 본문 전에 조건을 검사해 0번 실행될 수 있고 do-while은 본문 뒤에 검사해 최소 한 번 실행되며 for는 초기화 후 조건 검사 본문 갱신을 반복한다는 세 흐름도](/materials/diagrams/cpp-02-loops.svg)](/materials/diagrams/cpp-02-loops.svg)

*그림 2-4 · 세 반복문의 흐름 — 누르면 원본 크기로 열린다.*

```cpp
// while: 조건이 거짓이 될 때까지 본문(body)을 반복
while (grade < cutoff) { lettergrade = lettergrade + 1; cutoff = cutoff - 10; }

// do-while: 조건이 아래에 있어 본문이 최소 한 번 실행
i = 1;
do
    std::cout << "i is " << i++ << endl;
while (i <= 10);

// for (초기화; 조건; 갱신)
for (i = 1; i < 10; i++) cout << "i is " << i << endl;
```

- `for`의 **초기화**는 처음 한 번만, **조건**이 참인 동안 본문 실행, **갱신**은 본문이 끝날 때마다(조건 검사 전에) 실행됩니다.
- 모든 `for`는 `while`로, 모든 `while`은 `for`로 바꿀 수 있습니다.
- 초기화·조건·갱신은 비워 둘 수 있고, **조건을 비우면 끝나지 않습니다**: `for (i = 0; ; i++)`.
- `break`는 반복을 끝내고, `continue`는 남은 본문을 건너뛰고 **조건 검사(for는 갱신)**로 갑니다.

### 세 반복문 비교

| 반복문 | 조건 검사 시점 | 최소 실행 횟수 | 주로 쓰는 경우 |
| --- | --- | ---: | --- |
| `while (조건) { }` | 본문 **전** | 0 | 횟수를 모르고 조건으로 반복 |
| `do { } while (조건);` | 본문 **후** | **1** | 입력을 먼저 받고 검사 |
| `for (초기식; 조건; 증감식) { }` | 본문 **전** | 0 | 횟수가 정해진 반복 |

`for`의 실행 순서: **초기식(한 번) → 조건 → 본문 → 증감식 → 조건 → 본문 → …**

### while ↔ for 변환

```cpp
초기식;                          for (초기식; 조건; 증감식) {
while (조건) {          ↔            본문;
    본문;                        }
    증감식;
}
```

> [!TRAP]
> - **반복 후 변수 값**: `for (int j = 0; …)`처럼 `for` 안에서 선언한 변수는 반복문이 끝나면 **사라집니다**. 반복 후에도 `j`를 쓰려면 바깥에서 선언하고 `for (; j <= 10; j++)`처럼 씁니다.
> - 반복이 끝난 시점의 변수는 **조건을 처음 거짓으로 만든 값**입니다. `j <= 10`이면 끝난 뒤 `j`는 11입니다.
> - `for (…);`처럼 괄호 뒤에 세미콜론을 붙이면 **빈 문장이 본문**이 되어, 아래 블록은 반복이 끝난 뒤 한 번만 실행됩니다.
> - `do while`은 끝에 **세미콜론**이 필요합니다.

### break와 continue

| 키워드 | 동작 |
| --- | --- |
| `break` | **가장 안쪽** 반복문(또는 switch) 하나를 즉시 빠져나감 |
| `continue` | 이번 회차의 나머지를 건너뛰고 다음 회차로 |

> [!TRAP]
> `continue` 뒤에 가는 곳이 반복문마다 다릅니다.
> - `for`: **증감식**으로 갑니다. 증감은 항상 실행됩니다.
> - `while`: **조건**으로 바로 갑니다. 본문 끝의 `i++`를 건너뛰면 **무한 반복**이 됩니다.
>
> ```cpp
> int i = 0;
> while (i < 5) {
>     if (i == 2) continue;   // i가 2에서 영원히 멈춤
>     cout << i;
>     i++;
> }
> ```

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> // (1)
> int y = 1;
> for (int i = 5; i > 0; i--) {
>     if (i % 2 == 1) y = y + i;
>     else y++;
>     cout << y << ' ';
> }
>
> // (2)
> int i = 10;
> do { cout << i; i++; } while (i < 5);
> cout << " i=" << i;
>
> // (3)
> int k;
> for (k = 0; k < 10; k += 3);
> cout << k;
>
> // (4)
> int n = 1, total = 0;
> while (n < 20) {
>     if (n % 3 == 0) { n++; continue; }
>     if (n > 10) break;
>     total += n;
>     n++;
> }
> cout << total << ' ' << n;
> ```

> [!ANSWER]
> **(1)** `6 7 10 11 12 ` — i = 5, 3, 1(홀수)에서는 i를 더하고, 4, 2에서는 1을 더합니다.
>
> **(2)** `10 i=11` — `do while`은 조건(10 < 5)이 거짓이어도 한 번 실행합니다.
>
> **(3)** `12` — `for` 뒤의 `;` 때문에 본문이 비어 있습니다. k = 0, 3, 6, 9, 12에서 조건이 거짓이 되어 멈춥니다.
>
> **(4)** `37 11` — 3의 배수(3, 6, 9)는 건너뛰고, 1 + 2 + 4 + 5 + 7 + 8 + 10 = 37. n = 11에서 `break`.

> [!QUIZ]
> 다음 `while`문을 같은 동작의 `for`문으로 바꾸고, 반복이 끝난 뒤 `sum`과 `j`의 값을 쓰시오. 두 변수는 반복문 밖에서도 사용해야 한다.
>
> ```cpp
> // (1)
> int sum = 0;
> int j = 0;
> while (j <= 10) {
>     sum = sum + j;
>     j++;
> }
>
> // (2)
> int sum = 0;
> int j = 5;
> while (j > 0)
>     sum = sum + j--;
> ```

> [!ANSWER]
> ```cpp
> // (1)
> int sum = 0;
> int j = 0;
> for (; j <= 10; j++)
>     sum = sum + j;
>
> // (2)
> int sum = 0;
> int j = 5;
> for (; j > 0; j--)
>     sum = sum + j;
> ```
>
> (1) `sum = 55`, `j = 11`. (2) `sum = 15`, `j = 0`. (2)의 `j--`는 후위이므로 **현재 값을 더한 뒤** 감소합니다. `for`로 옮길 때는 감소를 증감식 자리로 빼야 합니다. 초기식을 `for` 안에서 `int j = 0`으로 선언하면 반복 후 `j`를 쓸 수 없습니다.

## 6. 중첩 반복문과 범위 기반 for

바깥 반복이 한 번 돌 때마다 안쪽 반복이 **처음부터 끝까지** 돕니다. 안쪽 반복의 범위가 바깥 변수에 따라 바뀌면 표를 그려 횟수를 셉니다.

```cpp
for (int i = 1; i <= 4; i++) {        // 줄
    for (int j = 1; j <= i; j++)      // i번 반복
        cout << '*';
    cout << '\n';
}
```

```text
*
**
***
****
```

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> // (1)
> int cnt = 0;
> for (int i = 0; i < 4; i++)
>     for (int j = i; j < 4; j++)
>         cnt++;
> cout << cnt << '\n';
>
> // (2)
> for (int i = 1; i <= 3; i++)
>     for (int j = 1; j <= 3; j++) {
>         if (j == 2) break;
>         cout << i << j << ' ';
>     }
> ```

> [!ANSWER]
> **(1)** `10` — i = 0, 1, 2, 3일 때 안쪽이 4, 3, 2, 1번 돌아 4 + 3 + 2 + 1 = 10.
>
> **(2)** `11 21 31 ` — `break`는 **안쪽** 반복만 끝냅니다. 바깥 반복은 계속되므로 i마다 j = 1만 출력됩니다.

**범위 기반 for (C++11)** — 컨테이너의 원소를 처음부터 끝까지 바로 꺼냅니다.

```cpp
vector<int> nums = {1, 2, 3, 4};
for (int x : nums) cout << x << " ";   // 1 2 3 4
```

```cpp
vector<int> v = {1, 2, 3};
for (int x : v) cout << x;        // 복사본으로 읽기
for (int& x : v) x *= 2;          // 참조로 원본 수정
for (const int& x : v) cout << x; // 복사 없이 읽기만
```

## 7. 컴파일 오류와 정의되지 않은 동작

시험에서는 "컴파일 오류 / 실행 시 문제(UB) / 정상"을 구분하라고 자주 묻습니다.

| 코드 | 판정 | 이유 |
| --- | --- | --- |
| `char g = "A";` | 컴파일 오류 | 문자열을 `char`에 저장할 수 없음 |
| `int k{3.5};` | 컴파일 오류 | 중괄호 초기화의 축소 변환 금지 |
| `do { … } while (x)` (세미콜론 없음) | 컴파일 오류 | 문법 오류 |
| `5.5 % 2` | 컴파일 오류 | `%`는 정수 전용 |
| `int x; cout << x;` | UB | 초기화하지 않은 값 읽기 |
| `int r = 10 / 0;` | UB | 정수를 0으로 나눔 |
| `int big = 2147483647; big++;` | UB | signed 오버플로 |
| `i++ + ++i` | UB | 한 식에서 같은 변수를 두 번 변경 |
| `unsigned int u = -1;` | 정상 | 4294967295로 정해져 있음 |
| `if (x = 5)` | 정상(논리 오류) | 대입식이 항상 참 |
| `int i = 0; while (i < 5) { }` | 정상(무한 반복) | `i`가 바뀌지 않음 |

## 핵심 정리

1. 섞인 식은 넓은 쪽으로 자동 변환(bool·char·short → int → … → double). 결과도 가장 넓은 형.
2. 좁은 형에 넣으면 조용히 값이 잘린다(3.14 → 3). 원하는 변환은 `(double)7 / 2`처럼 명시한다.
3. 0.1 같은 소수는 정확히 표현되지 않아 합이 조금씩 어긋난다.
4. `&&`·`||`는 단락 평가, `!`는 0/1. `x++`는 읽고 증가, `++x`는 증가하고 읽기. 한 식에서 같은 변수를 두 번 바꾸지 않는다.
5. 우선순위: `()` > `++ --` > `* / %` > `+ -` > 비교 > `== !=` > `&&` > `||` > `=`. 대입만 오른쪽부터.
6. `if (x = 5)`는 대입이라 항상 참. switch는 break까지 내려가고 double 불가.
7. while은 0번 가능, do-while은 최소 1번, for = 초기화 1번 + (조건 → 본문 → 갱신) 반복.
