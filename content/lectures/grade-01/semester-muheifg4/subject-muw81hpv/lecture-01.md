# C++ 시작하기

**슬라이드:** Lecture 2 (2주차) · Introduction, Basic Datatypes, “Hello World”-Program

이 강의는 C++ 프로그램 한 장이 **어떻게 만들어지고 실행되는지**, 그 안에서 **값이 어떻게 저장되고 계산되는지**를 다룹니다. 처음 프로그래밍을 배우는 사람을 기준으로 썼습니다.

```text
C++의 역사와 위치 → 컴파일과 전처리(#include, #define)
```

## 1. C++은 어디서 왔고 어디쯤 있나

| 연도 | 사건 |
| --- | --- |
| 1960–70년대 | Bell Labs의 Dennis Ritchie가 시스템 프로그래밍용 **C 언어**를 만듦 |
| 1979–83 | Bjarne Stroustrup이 C에 클래스·상속·다형성을 더한 **C with Classes** |
| 1983 | Rick Mascitti가 **“C++”**이라는 이름을 제안 (`++`는 “C보다 하나 더”) |
| 1985 | AT&T의 첫 상용 컴파일러 **CFront** |
| 1987 | Microsoft C++ 1.0, GCC의 C++ 지원 |
| 1993 | 고품질 라이브러리 모음 **Boost** 시작 |
| 1998 | ANSI/ISO 표준 **C++98** (예외 처리 명세 포함) |
| 2003 | **C++03**, 표준 템플릿 라이브러리(**STL**) |
| 2011–14 | **C++11/14**: 스마트 포인터, 람다 등 큰 변화 |
| 2017–20 | **C++17/20**: 모듈, 콘셉트, 레인지 |

**절차형 vs 객체지향**

| | 절차형(C, Pascal, Fortran) | 객체지향(Java, C#, Smalltalk) |
| --- | --- | --- |
| 중심 | 절차와 함수 | 객체와 클래스 |
| 데이터 | 함수와 따로 | 메서드와 함께 클래스 안에 캡슐화 |
| 재사용 | 함수 | 상속과 다형성 |

**C++은 두 방식을 모두 지원합니다.** 이 과목도 중간고사 전에는 절차형, 그 뒤에는 객체지향을 배웁니다.

**다른 언어와 비교**

| 언어 | 그 언어의 특징 | C++과의 차이 |
| --- | --- | --- |
| Java / C# | 플랫폼 독립, 강한 객체지향, **자동 메모리 관리** | C++은 이식성보다 **성능**, 메모리를 **직접 관리** |
| Python | 읽기 쉬움, 자동 메모리 관리, AI(PyTorch)·웹·데이터 | C++은 문법이 복잡하지만 **하드웨어 가까이**에서 메모리를 세밀하게 제어 |
| Rust | **소유권 시스템**과 엄격한 컴파일 검사로 메모리 오류 예방, 객체지향 대신 trait | C++은 수동 메모리 관리라 실수 위험, 메모리 취약점 대책이 부족 |

> [!NOTE]
> “C++은 빠르지만 위험하다”가 한 줄 요약입니다. 메모리를 직접 다루는 대가로 성능을 얻습니다. 05강의 포인터와 동적 메모리가 바로 그 “직접 다루기”입니다.

## 2. 컴파일과 전처리

[![직접 작성한 C++ 프로그램이 전처리기에서 include와 define이 펼쳐진 임시 파일이 되고 컴파일러가 실행 파일로 바꾸는 과정](/materials/diagrams/cpp-01-build-pipeline.svg)](/materials/diagrams/cpp-01-build-pipeline.svg)

*그림 1-1 · 소스 코드가 실행 파일이 되기까지 — 누르면 원본 크기로 열린다.*

**컴파일러**는 사람이 쓴 C++ 코드를 컴퓨터가 실행하는 **기계어(실행 파일)**로 바꾸는 프로그램입니다. 대표적으로 Microsoft Visual C++(Visual Studio Community), GCC(g++), Apple Xcode가 있습니다. 수업에서는 Visual C++를 쓰지만 과제에는 어떤 컴파일러를 써도 됩니다.

**전처리기(preprocessor)**는 컴파일 **전에** 자동으로 실행되어 `#`으로 시작하는 줄(**지시문**)을 처리합니다. 따로 실행할 필요는 없습니다.

| 지시문 | 하는 일 |
| --- | --- |
| `#include` | 헤더 파일 내용을 그 자리에 **붙여 넣기** |
| `#define` | 매크로·상수 정의 (이름을 값으로 **글자 그대로 바꾸기**) |
| `#undef` | 매크로 정의 취소 |
| `#if` / `#elif` / `#else` / `#endif` | 조건부 컴파일 |
| `#ifdef` / `#ifndef` | 매크로가 정의되었는지 / 안 되었는지 검사 (헤더 가드에 사용) |
| `#error` | 컴파일 오류를 일부러 냄 |
| `#pragma` | 컴파일러별 지시 |

```cpp
#include <iostream>   // std::cin, std::cout, std::cerr를 쓰게 해 줌
#define NUM 45
y = NUM + NUM;        // 전처리 후: y = 45 + 45;
```

**매개변수가 있는 매크로**는 함수처럼 보이지만 **글자 치환**일 뿐입니다.

```cpp
#define SQUARE(x)  ((x) * (x))
SQUARE(i + 2)        // → ((i + 2) * (i + 2))
```

> [!TRAP]
> 괄호를 빼고 `#define SQUARE(x) x * x`라고 쓰면 `SQUARE(i + 2)`는 `i + 2 * i + 2`가 되어 엉뚱한 값이 나옵니다. 매크로는 **계산하지 않고 글자만 바꾼다**는 것을 기억하세요. 그래서 상수는 `#define`보다 `const`(03강)를 권합니다.

## 3. Hello World 한 줄씩 읽기

```cpp
// Hello World program                       ← 주석
#include <iostream>                          // 입출력 라이브러리를 포함
int main() {                                 // 특별한 함수 main의 정의 시작
    std::cout << "Hello World" << std::endl; // 문자열 출력, 줄 바꾸고 버퍼 비우기
    return 0;                                // 상태 코드 반환 (0은 보통 "정상")
}
```

- 프로그램은 항상 **`main` 함수**에서 시작합니다.
- `std::cout << 값`은 값을 화면에 출력합니다. `<<`를 이어 붙여 여러 값을 출력합니다.
- `std::endl`은 줄을 바꾸고 출력 버퍼를 비웁니다. 줄만 바꿀 때는 `"\n"`도 씁니다.
- `std::`는 표준 라이브러리 **네임스페이스**입니다(03강). `using namespace std;`를 쓰면 생략할 수 있습니다.

**주석**은 컴파일러가 무시하는 설명입니다. `//` 뒤는 줄 끝까지, `/*`와 `*/` 사이는 여러 줄을 무시합니다.

```cpp
#include <iostream>      // cin, cout을 쓰기 위한 헤더
using namespace std;     // std:: 생략

int main() {             // 프로그램의 시작점
    int age;
    cin >> age;                          // 입력
    cout << "age: " << age << endl;      // 출력 + 줄바꿈 + 버퍼 비우기
    return 0;                            // 0 = 정상 종료
}
```

| 요소 | 기억할 점 |
| --- | --- |
| `#include <iostream>` | `cin`, `cout` 사용에 필요 |
| `using namespace std;` | 없으면 `std::cout`, `std::cin`, `std::string`처럼 써야 함 |
| `main` | 반드시 하나 있어야 함. 없으면 링크 오류 |
| `endl` vs `'\n'` | 둘 다 줄바꿈. `endl`은 출력 버퍼도 비움 |

## 4. 변수·자료형·리터럴

**변수**는 메모리의 한 칸에 붙인 이름입니다. 변수는 반드시 **자료형**이 있고, **쓰기 전에 선언**해야 하며, 선언하면서 바로 초기화할 수 있습니다(`int i = 5;`).

- 이름은 글자·숫자·밑줄(`_`)로 만들고 **숫자로 시작할 수 없습니다.**
- **대소문자를 구분**합니다: `foo`와 `Foo`는 다른 변수입니다.
- 좋은 이름은 그 변수가 무엇에 쓰이는지 알려 줍니다.

```cpp
#include <iostream>
#include <string>
int main() {
    int age = 20;
    double height = 1.75;
    std::string name = "Alex";
    std::cout << name << " is " << age << " years old and " << height << " m tall.\n";
}
// 출력: Alex is 20 years old and 1.75 m tall.
```

| 자료형 | 저장하는 것 |
| --- | --- |
| `char` | 1바이트, 문자 하나 |
| `int` | 정수 (보통 그 컴퓨터에 자연스러운 크기, 4바이트) |
| `float` | 단정밀도 실수 |
| `double` | 배정밀도 실수 |
| `bool` | `true` 또는 `false` |
| `std::string` | 문자열(텍스트), `<string>` 필요 |

**리터럴**은 코드에 직접 쓴 고정 값이고, 모양에 따라 자료형이 정해집니다: `42`(int), `3.14`(double), `'A'`(char), `0x2A`(16진수 int, 값 42), `false`(bool), `"Hi Dave"`(문자열).

**고정 폭 정수(`<cstdint>`)** — `int`의 크기는 컴퓨터마다 다를 수 있어서, 크기를 정확히 정한 자료형을 씁니다.

| 자료형 | 크기 |
| --- | --- |
| `int8_t` / `uint8_t` | 8비트 부호 있음 / 없음 |
| `int16_t` / `uint16_t` | 16비트 |
| `int32_t` / `uint32_t` | 32비트 |
| `int64_t` / `uint64_t` | 64비트 |

크기를 명시해 **이식성**이 좋아지고 `int`/`long`의 모호함이 없어집니다.

**bool과 정수** — C++의 참·거짓은 C에서 왔습니다. **0은 거짓, 0이 아닌 값은 모두 참**이고, `true`는 1, `false`는 0인 정수처럼 동작합니다(보통 1바이트).

| 자료형 | 저장 대상 | 리터럴 예 | 주의 |
| --- | --- | --- | --- |
| `char` | 문자 1개 (실제로는 작은 정수) | `'A'` | 작은따옴표 |
| `int` | 정수 (보통 32비트) | `42`, `0x2A` | 약 ±21억 |
| `long long` | 큰 정수 (64비트) | `8000000000LL` | |
| `float` | 단정밀도 실수 | `3.14f` | `f`가 없으면 `double` |
| `double` | 배정밀도 실수 | `3.14` | 실수 리터럴의 기본형 |
| `bool` | 참/거짓 | `true`, `false` | 출력하면 `1`, `0` |
| `string` | 문자열 (클래스) | `"Hello"` | `#include <string>` |

### 문자는 정수 코드다 (아스키 코드)

`char`는 문자 하나를 **정수 코드**로 저장합니다. 산술 연산을 하면 `int`로 바뀌어 계산됩니다.

| 문자 | 코드 | 문자 | 코드 |
| --- | ---: | --- | ---: |
| `'0'` | 48 | `'A'` | 65 |
| `'9'` | 57 | `'Z'` | 90 |
| `'\0'` (널 문자) | 0 | `'a'` | 97 |
| `' '` (공백) | 32 | `'z'` | 122 |

```cpp
char c = 'A';
cout << c;             // A        (char로 출력)
cout << c + 1;         // 66       (int로 바뀜)
cout << char(c + 1);   // B        (다시 char로 변환)
cout << '7' - '0';     // 7        (숫자 문자 → 정수 값)
cout << 'c' - 'a';     // 2        (알파벳 순번)
```

> [!TRAP]
> - `'7'`은 정수 7이 아니라 코드 55인 **문자**입니다. 숫자 값이 필요하면 `'7' - '0'`.
> - `"A"`는 문자 하나가 아니라 `'A'`와 `'\0'`으로 된 **문자열**입니다. `char g = "A";`는 컴파일 오류입니다.
> - 대문자가 소문자보다 코드가 **작습니다**. `'a' < 'B'`는 거짓(97 < 66)입니다.

### 초기화하지 않은 지역 변수

함수 안에서 초기값 없이 선언한 기본 자료형 변수는 **쓰레기 값**을 가집니다. 읽으면 결과를 예측할 수 없습니다. 전역 변수와 `static` 변수는 자동으로 0이 됩니다.

```cpp
int count;          // 함수 안: 값이 정해지지 않음
int total = 0;      // 항상 초기화하는 습관
int score{0};       // 중괄호 초기화도 가능
```

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> char c = 'A';
> cout << c + 1 << ' ' << char(c + 1) << ' ' << c << '\n';
> cout << '7' - '0' << ' ' << ('a' < 'B') << '\n';
> ```

> [!ANSWER]
> ```text
> 66 B A
> 7 0
> ```
>
> `c + 1`은 `int` 66, `char(c + 1)`은 `'B'`입니다. `c` 자체는 바뀌지 않습니다. `'a'`(97)는 `'B'`(66)보다 크므로 `'a' < 'B'`는 0입니다.

## 5. 입력 std::cin

```cpp
// C++ Addition of integers
#include <iostream>
int main() {
    int integer1, integer2, sum;
    std::cout << "Enter first integer\n";
    std::cin >> integer1;
    std::cout << "Enter second integer\n";
    std::cin >> integer2;
    sum = integer1 + integer2;
    std::cout << "Sum is " << sum << std::endl;
    return 0;
}
```

- `std::cin >> 변수`는 키보드 입력을 읽어 변수에 넣습니다(추출 연산자 `>>`).
- `std::cin >> x >> y;`처럼 여러 값을 이어서 읽을 수 있습니다(공백으로 구분).
- 입력은 자료형을 따집니다. `int` 변수에 글자를 입력하면 읽기가 실패해 엉뚱하게 동작합니다.

**화씨 → 섭씨 변환 (Lecture 2 마지막 예제)**

```cpp
double fahr, celcius;
std::cin >> fahr;
celcius = (fahr - 32.0) * 5.0 / 9.0;
```

`(fahr - 32) * (5 / 9)`로 쓰면 `5 / 9`가 **정수 나눗셈**이라 0이 되어 결과가 항상 0입니다. 다음 절이 그 이유입니다.

## 6. 정수 나눗셈과 나머지 `%`

**두 피연산자가 모두 정수**이면 결과도 정수이고, 소수 부분은 **0 쪽으로 잘립니다**(버림이 아니라 절단).

| 식 | 결과 | 이유 |
| --- | ---: | --- |
| `7 / 2` | `3` | 3.5 → 3 |
| `-7 / 2` | `-3` | −3.5 → −3 (0 쪽으로) |
| `7 / 2.0` | `3.5` | 하나라도 실수면 실수 나눗셈 |
| `7 % 3` | `1` | 7 = 3 × 2 + 1 |
| `-7 % 3` | `-1` | 나머지의 부호 = **왼쪽** 피연산자의 부호 |
| `7 % -3` | `1` | 왼쪽이 양수 |

규칙: `a == (a / b) * b + a % b`가 항상 성립합니다.

> [!TRAP]
> - `n % 2 == 1`로 홀수를 판별하면 **음수 홀수에서 틀립니다**(`-7 % 2`는 `-1`). 홀수 판별은 `n % 2 != 0`이 안전합니다.
> - `%`는 정수에만 쓸 수 있습니다. `5.5 % 2`는 컴파일 오류입니다.
> - 정수를 0으로 나누거나 `% 0`을 하면 **정의되지 않은 동작(UB)**입니다.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> cout << 7 / 2 << ' ' << -7 / 2 << ' ' << 7 % 3 << ' '
>      << -7 % 3 << ' ' << 7 % -3 << '\n';
> ```

> [!ANSWER]
> ```text
> 3 -3 1 -1 1
> ```
>
> 나눗셈은 0 쪽으로 절단되고, 나머지의 부호는 왼쪽 피연산자를 따릅니다.

## 7. 산술·대입·비교 연산자와 오버플로

| 연산자 | 이름 | 예 | 결과 |
| --- | --- | --- | --- |
| `+` | 덧셈 | `5 + 3` | 8 |
| `-` | 뺄셈 | `5 - 3` | 2 |
| `*` | 곱셈 | `5 * 3` | 15 |
| `/` | 나눗셈 | `6 / 3` | 2 |
| `%` | 나머지 | `5 % 3` | 2 |

**대입 `=`**은 오른쪽 식의 값을 왼쪽 변수에 넣습니다(`x = 13 - y;`). 우선순위가 매우 낮고 **오른쪽에서 왼쪽으로** 결합하므로 `x = y = z + 15;`가 됩니다(`z + 15`를 y에 넣고, 그 값을 x에 넣음).

**비교 연산자**는 참·거짓(1 또는 0)을 돌려줍니다.

| 연산자 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `<` `>` | 작다 / 크다 | `5 < 8` | true |
| `<=` `>=` | 작거나 같다 / 크거나 같다 | `5 <= 5` | true |
| `==` | 같다 | `5 == 5` | true |
| `!=` | 다르다 | `5 != 8` | true |

**결합성과 우선순위** — `3 / 4 / 5`처럼 같은 연산자가 이어지면 **왼쪽부터**(결합성), 다른 연산자가 섞이면 **우선순위가 높은 것부터** 계산합니다. 전체 사다리는 02강 2절에 그림으로 정리했습니다.

> [!QUIZ]
> 슬라이드 질문: `2 / 3 / 4 + 5`의 값은?

> [!ANSWER]
> **5**. `2 / 3`은 정수 나눗셈이라 0, `0 / 4`도 0, `0 + 5` = 5.

**오버플로 (Lecture 2 슬라이드 35–36)**

- **signed 정수**가 범위를 넘으면 **정의되지 않은 동작(UB)** — C++20, C++23, C++26 초안에서도 마찬가지.
- **unsigned 정수**는 범위를 넘으면 **0부터 다시 돈다**(모듈로 산술): `UINT_MAX + 1`은 0.
- 표준에는 오버플로를 감지하거나 막는 장치가 없습니다. Rust(`checked_add` 등)나 Swift(`&+`)는 따로 제공합니다.

### signed 오버플로 = 정의되지 않은 동작

32비트 `int`의 범위는 −2,147,483,648 ~ 2,147,483,647입니다. 이를 넘는 **부호 있는 정수**의 결과는 **UB**입니다. "최댓값 + 1 = 최솟값"이라고 가정하면 안 됩니다.

```cpp
int big = 2147483647;
big = big + 1;          // UB
long long safe = 2147483647LL + 1;   // 2147483648
```

### unsigned는 범위를 넘으면 돌아간다 (규칙이 정해져 있음)

`unsigned int`(32비트)는 0 ~ 4,294,967,295이고, 범위를 넘으면 **2³²로 나눈 나머지**로 돌아갑니다. 이 동작은 표준이 보장합니다.

```text
0 - 1                  → 4294967295   (0 아래로 가면 최댓값)
4294967295 + 2         → 1
unsigned int u = -1;   → 4294967295   (−1을 넣어도 최댓값)
```

> [!TRAP]
> **unsigned와 signed를 섞어 비교하면 signed 값이 unsigned로 바뀝니다.**
>
> ```cpp
> int i = -1;
> unsigned int k = 1;
> cout << (i < k);     // 0 !  (−1이 4294967295로 바뀜)
> ```
>
> **unsigned로 거꾸로 세는 반복문은 끝나지 않습니다.**
>
> ```cpp
> for (unsigned int j = 3; j >= 0; j--)   // j >= 0은 항상 참
>     cout << j;                          // 3 2 1 0 4294967295 ... 무한 반복
> ```
>
> Homework 2의 `sum_down`을 `unsigned int`로 바꾸면 안 되는 이유가 바로 이것입니다. `x = 0`에서 `x - 1`이 −1이 아니라 4294967295가 되어 기저 조건 `x < 0`에 도달하지 못합니다.

> [!QUIZ]
> 다음 출력을 쓰시오.
>
> ```cpp
> unsigned int u = 0;
> u = u - 1;
> cout << u << '\n';
> int i = -1;
> unsigned int k = 1;
> cout << (i < k) << ' ' << (i < (int)k) << '\n';
> unsigned int big = 4294967295u;
> big = big + 2;
> cout << big << '\n';
> ```

> [!ANSWER]
> ```text
> 4294967295
> 0 1
> 1
> ```
>
> `i < k`에서는 `i`가 unsigned로 바뀌어 4294967295 < 1이 되어 거짓입니다. `k`를 `int`로 바꾸면 −1 < 1로 참입니다. 4294967295 + 2는 한 바퀴 돌아 1입니다.

## 핵심 정리

1. C++은 C에 객체지향을 더한 언어로, 절차형과 객체지향을 모두 지원한다. 성능을 위해 메모리를 직접 관리한다.
2. 전처리(`#include` 붙여 넣기, `#define` 글자 치환) → 컴파일 → 실행 파일. 매크로는 계산하지 않고 글자만 바꾼다.
3. 프로그램은 `main`에서 시작하고 `std::cout <<`로 출력, `std::cin >>`으로 입력한다.
4. 변수는 자료형이 있고 쓰기 전에 선언한다. 대소문자 구분, 숫자로 시작 불가.
5. 0은 거짓, 0이 아니면 참. `true`는 1, `false`는 0.
6. 정수끼리 나누면 몫만 남는다(`5 / 9` = 0). `%`는 나머지.
7. signed 오버플로는 UB, unsigned는 0부터 다시 돈다.
