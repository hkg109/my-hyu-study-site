## Exercise 02

### Quiz 1 - 쇼핑 금액 계산

**난이도:** 중하

#### 요구사항

- 상품의 가격 price, 수량 quantity, 할인액 discount를 입력받습니다.
- 상품 가격에 수량을 곱한 뒤 할인액을 정확히 한 번만 뺍니다.
- 최종 결제 금액을 total에 저장하여 출력합니다.

#### 입력

한 줄에 세 정수 price, quantity, discount가 주어집니다.

#### 출력

최종 결제 금액을 정수로 출력합니다.

#### 입력 예시

~~~text
1500 4 1000
~~~

#### 출력 예시

~~~text
5000
~~~

#### 접근 방법

- 가격은 1 이상 10,000 이하이고 수량은 1 이상 100 이하입니다.
- 할인 전 최대 금액은 10,000 × 100 = 1,000,000이므로 int 범위에 충분히 들어갑니다.
- discount는 전체 상품 금액 이하이므로 결과는 음수가 되지 않습니다.
- 할인은 상품 하나마다 적용하는 것이 아니라 전체 금액에서 정확히 한 번만 뺍니다.

계산식은 다음과 같습니다.

~~~text
total = price * quantity - discount
~~~

<Answer>

~~~cpp title="exercise02_quiz1.cpp" showLineNumbers
#include <iostream>
using namespace std;

int main() {
    // 각 입력과 최대 결제 금액(10,000 * 100 = 1,000,000)이
    // 모두 int 범위 안이므로 메모리가 더 큰 자료형은 필요하지 않다.
    int price;
    int quantity;
    int discount;

    // 상품 가격, 수량, 전체 주문 할인액을 차례로 입력받는다.
    cin >> price >> quantity >> discount;

    // 먼저 상품 가격에 수량을 곱하고, 할인액은 전체에서 한 번만 뺀다.
    int total = price * quantity - discount;

    // 문제에서 요구한 최종 결제 금액만 출력한다.
    cout << total << '\n';

    return 0;
}
~~~

</Answer>

#### 복잡도

- 시간 복잡도: O(1)
- 공간 복잡도: O(1)

### Quiz 2 - 경과 시간 변환

**난이도:** 중

#### 요구사항

- Day 0의 00:00:00부터 흐른 총 초를 입력받습니다.
- 총 초를 일, 시, 분, 초로 나눕니다.
- PDF에 지정된 라벨과 순서를 바꾸지 않고 출력합니다.

#### 입력

0 이상 1,000,000,000 이하의 정수 elapsedSeconds가 주어집니다.

#### 출력

Days, Hours, Minutes, Seconds 라벨 뒤에 변환된 값을 출력합니다.

#### 입력 예시

~~~text
93605
~~~

#### 출력 예시

~~~text
Days: 1 Hours: 2 Minutes: 0 Seconds: 5
~~~

#### 접근 방법

- 하루는 24 × 60 × 60 = 86,400초입니다.
- 전체 초를 86,400으로 나눈 몫이 날짜이고, 나머지는 그날 안에서 흐른 초입니다.
- 남은 초를 3,600으로 나눈 몫이 시간입니다.
- 다시 남은 초를 60으로 나눈 몫과 나머지가 각각 분과 초입니다.
- 입력과 모든 중간 계산값이 1,000,000,000을 넘지 않으므로 int로 안전하게 표현할 수 있습니다.
- 시는 0에서 23, 분과 초는 0에서 59 사이가 되도록 매 단계에서 나머지를 갱신합니다.

<Answer>

~~~cpp title="exercise02_quiz2.cpp" showLineNumbers
#include <iostream>
using namespace std;

int main() {
    // 최댓값 1,000,000,000과 모든 나머지는 int 범위 안에 있다.
    // 날짜, 시간, 분, 초도 이 값보다 작으므로 같은 int 자료형을 사용한다.
    int elapsedSeconds;
    cin >> elapsedSeconds;

    // 시간 단위는 변하지 않는 정수이므로 const int로 선언한다.
    const int secondsPerMinute = 60;
    const int secondsPerHour = 60 * secondsPerMinute;
    const int secondsPerDay = 24 * secondsPerHour;

    // 전체 초에서 완전히 지난 날짜 수를 구한다.
    int days = elapsedSeconds / secondsPerDay;
    elapsedSeconds %= secondsPerDay;

    // 하루를 제외하고 남은 초에서 시간을 구한다.
    int hours = elapsedSeconds / secondsPerHour;
    elapsedSeconds %= secondsPerHour;

    // 한 시간을 제외하고 남은 초에서 분을 구한다.
    int minutes = elapsedSeconds / secondsPerMinute;

    // 60으로 나눈 나머지가 마지막 초가 된다.
    int seconds = elapsedSeconds % secondsPerMinute;

    // PDF에 제시된 라벨과 순서를 그대로 사용한다.
    cout << "Days: " << days
         << " Hours: " << hours
         << " Minutes: " << minutes
         << " Seconds: " << seconds << '\n';

    return 0;
}
~~~

</Answer>

#### 계산 확인

93605초를 변환하면 다음과 같습니다.

~~~text
93605 / 86400 = 1일, 나머지 7205초
7205 / 3600 = 2시간, 나머지 5초
5 / 60 = 0분, 나머지 5초
~~~

#### 복잡도

- 시간 복잡도: O(1)
- 공간 복잡도: O(1)

## Exercise 03

### Quiz 1 - 최대공약수

**난이도:** 중

#### 요구사항

- 두 양의 정수의 최대공약수를 구합니다.
- 모든 약수를 직접 검사하지 않고 유클리드 호제법을 사용합니다.
- 결과 뒤에 줄바꿈을 출력합니다.

#### 입력

한 줄에 1 이상 1,000,000,000 이하의 두 정수 a, b가 주어집니다.

#### 출력

a와 b의 최대공약수를 출력합니다.

#### 입력 예시

~~~text
48 18
~~~

#### 출력 예시

~~~text
6
~~~

#### 접근 방법

- 모든 수를 1부터 차례로 검사하면 최대 10억 번의 검사가 필요하므로 너무 느립니다.
- 유클리드 호제법의 성질 gcd(a, b) = gcd(b, a % b)를 사용합니다.
- b가 0이 될 때 남아 있는 a가 최대공약수입니다.
- 반복할 때마다 두 번째 값이 나머지로 작아지므로 매우 빠르게 종료됩니다.

<Answer>

~~~cpp title="exercise03_quiz1.cpp" showLineNumbers
#include <iostream>
using namespace std;

int main() {
    // a와 b는 최대 1,000,000,000이고 나머지는 항상 b보다 작다.
    // 따라서 모든 계산이 int 범위 안에서 이루어진다.
    int a;
    int b;
    cin >> a >> b;

    // b가 0이 될 때까지 유클리드 호제법을 반복한다.
    while (b != 0) {
        // 다음 단계에서 사용할 나머지를 먼저 보관한다.
        int remainder = a % b;

        // gcd(a, b)는 gcd(b, a % b)와 같다.
        a = b;
        b = remainder;
    }

    // 반복이 끝나면 a에 최대공약수가 남는다.
    cout << a << '\n';

    return 0;
}
~~~

</Answer>

#### 예시 흐름

입력이 48과 18일 때:

~~~text
48 % 18 = 12
18 % 12 = 6
12 % 6 = 0
최대공약수 = 6
~~~

#### 복잡도

- 시간 복잡도: O(log(min(a, b)))
- 공간 복잡도: O(1)

### Quiz 2 - 연속 부분 배열의 최대 합

**난이도:** 중상

#### 요구사항

- 하나 이상의 연속된 원소를 선택합니다.
- 선택한 연속 구간에서 만들 수 있는 가장 큰 합을 구합니다.
- 모든 값이 음수인 경우도 올바르게 처리합니다.

#### 입력

첫째 줄에 1 이상 100 이하의 n이 주어지고, 둘째 줄에 -100 이상 100 이하의 정수 n개가 주어집니다.

#### 출력

비어 있지 않은 연속 부분 배열의 최대 합을 출력합니다.

#### 입력 예시

~~~text
5
-2 3 -1 4 -5
~~~

#### 출력 예시

~~~text
6
~~~

#### 접근 방법

- 연속 구간의 시작과 끝을 모두 시도하면 O(n²) 방식으로도 n=100에서는 통과할 수 있습니다.
- 하지만 각 위치에서 끝나는 최적의 합만 유지하는 카데인 알고리즘을 사용하면 O(n)에 해결할 수 있습니다.
- currentSum은 현재 원소에서 새 구간을 시작하는 값과 이전 구간에 현재 원소를 붙인 값 중 큰 값입니다.
- 모든 값이 음수일 수 있으므로 합을 0으로 초기화하면 안 됩니다. 첫 번째 입력값으로 currentSum과 maximumSum을 초기화해야 합니다.

~~~text
currentSum = max(현재 값, currentSum + 현재 값)
maximumSum = max(maximumSum, currentSum)
~~~

<Answer>

~~~cpp title="exercise03_quiz2.cpp" showLineNumbers
#include <algorithm>
#include <iostream>
using namespace std;

int main() {
    // n은 최대 100이므로 반복 횟수와 배열 위치는 int가 적합하다.
    int n;
    cin >> n;

    // 각 값은 -100~100이고 가능한 합도 -10,000~10,000이므로
    // value와 누적 합 모두 int로 안전하게 표현할 수 있다.
    int value;
    cin >> value;

    // 첫 값으로 초기화해야 모든 입력이 음수인 경우도 올바르게 처리된다.
    int currentSum = value;
    int maximumSum = value;

    for (int i = 1; i < n; i++) {
        cin >> value;

        // 이전 구간을 이어 갈지, 현재 값부터 새로 시작할지 선택한다.
        currentSum = max(value, currentSum + value);

        // 지금까지 발견한 가장 큰 연속 구간 합을 갱신한다.
        maximumSum = max(maximumSum, currentSum);
    }

    cout << maximumSum << '\n';
    return 0;
}
~~~

</Answer>

#### 예시 흐름

입력이 -2, 3, -1, 4, -5일 때 currentSum은 다음과 같이 변합니다.

~~~text
-2 → 3 → 2 → 6 → 1
~~~

그중 가장 큰 값인 6이 정답입니다. 모든 값이 음수인 경우에는 가장 큰 단일 원소가 정답이 됩니다.

#### 복잡도

- 시간 복잡도: O(n)
- 공간 복잡도: O(1)

## Exercise 04

### Quiz 1 - 모듈러 거듭제곱

**난이도:** 상

#### 요구사항

- a의 b제곱을 m으로 나눈 나머지를 구합니다.
- 지수를 절반씩 줄이는 분할 정복 방식을 사용합니다.
- 0의 0제곱은 1로 처리합니다.

#### 입력

한 줄에 정수 a, b, m이 주어집니다. a와 b는 0 이상 1,000,000,000 이하이고, m은 2 이상 1,000,000,000 이하입니다.

#### 출력

a의 b제곱을 m으로 나눈 나머지를 출력합니다.

#### 입력 예시

~~~text
2 10 1000
~~~

#### 출력 예시

~~~text
24
~~~

#### 접근 방법

- b가 최대 10억이므로 a를 b번 곱하는 O(b) 방식은 너무 느립니다.
- 실제 a의 b제곱은 자료형 범위를 훨씬 넘기므로 완성된 거듭제곱 값을 만든 뒤 나눌 수도 없습니다.
- 지수를 절반씩 줄이는 분할 정복 거듭제곱을 사용합니다.
- 곱셈할 때마다 m으로 나눈 나머지만 유지합니다.
- 지수가 짝수면 절반 거듭제곱의 제곱이고, 홀수면 거기에 a를 한 번 더 곱합니다.
- 두 나머지의 곱은 최대 약 10의 18제곱이므로 long long을 사용합니다.
- b가 0이면 a의 값과 관계없이 1을 반환하므로 0의 0제곱 조건도 처리됩니다.

<Answer>

~~~cpp title="exercise04_quiz1.cpp" showLineNumbers
#include <iostream>
using namespace std;

// 입력 자체는 int 범위지만, 나머지끼리 곱하면 약 10^18까지 커질 수 있다.
// 곱셈 중간값의 오버플로를 막기 위해 매개변수와 반환값을 long long으로 둔다.
long long modularPower(long long base, long long exponent, long long modulus) {
    // 지수가 0이면 문제의 정의에 따라 결과는 1이다.
    if (exponent == 0) {
        return 1;
    }

    // 지수를 절반으로 줄여 필요한 곱셈 횟수를 줄인다.
    long long half = modularPower(base, exponent / 2, modulus);

    // 중간값이 커지지 않도록 곱셈 직후 나머지를 구한다.
    long long result = (half * half) % modulus;

    // 홀수 지수라면 빠져 있는 base 한 개를 추가로 곱한다.
    if (exponent % 2 == 1) {
        result = (result * (base % modulus)) % modulus;
    }

    return result;
}

int main() {
    // 함수 안에서 두 나머지를 곱하므로 입력부터 long long으로 받아
    // 계산 중간에 int 곱셈이 먼저 수행되는 일을 막는다.
    long long a;
    long long b;
    long long m;
    cin >> a >> b >> m;

    cout << modularPower(a, b, m) << '\n';
    return 0;
}
~~~

</Answer>

#### 예시 흐름

2의 10제곱을 1000으로 나눈 나머지는 다음처럼 지수를 절반으로 줄여 계산할 수 있습니다.

~~~text
2^10 → (2^5)^2
2^5  → (2^2)^2 × 2
2^2  → (2^1)^2
~~~

#### 복잡도

- 시간 복잡도: O(log b)
- 공간 복잡도: O(log b) - 재귀 호출 스택

### Quiz 2 - 최소 변환 횟수

**난이도:** 최상

#### 요구사항

- 양의 정수 a에서 시작하여 b에 도달합니다.
- 한 번에 현재 값을 두 배로 만들거나 1을 뺄 수 있습니다.
- 계산 도중 값은 항상 양수여야 합니다.
- 필요한 연산 횟수의 최솟값을 구합니다.

#### 입력

한 줄에 1 이상 1,000,000,000 이하의 두 정수 a, b가 주어집니다.

#### 출력

a를 b로 바꾸는 최소 연산 횟수를 출력합니다.

#### 입력 예시

~~~text
4 7
~~~

#### 출력 예시

~~~text
2
~~~

#### 접근 방법

- a가 b보다 크거나 같으면 값을 늘리는 두 배 연산은 도움이 되지 않습니다. 1을 a-b번 빼는 것이 최적입니다.
- b가 더 크면 정방향에서 두 선택을 비교하기보다 b에서 a로 거꾸로 이동합니다.
- 정방향의 두 배 연산은 역방향에서 짝수를 2로 나누는 연산이 됩니다.
- 정방향의 1 빼기 연산은 역방향에서 1 더하기 연산이 됩니다.
- 현재 b가 홀수라면 어떤 정수의 두 배일 수 없으므로 먼저 1을 더해야 합니다.
- 현재 b가 짝수라면 2로 나누어 값을 가장 빠르게 줄입니다.
- 역방향 값이 a 이하가 되면, 남은 차이만큼 정방향에서 1을 빼면 됩니다.
- 입력과 역연산 중의 값, 최대 연산 횟수가 모두 10억 이하이므로 int로 안전하게 계산할 수 있습니다.

<Answer>

~~~cpp title="exercise04_quiz2.cpp" showLineNumbers
#include <iostream>
using namespace std;

int main() {
    // a와 b는 최대 1,000,000,000이고 역연산 중에도 이 범위를 넘지 않는다.
    // 최소 연산 횟수 역시 최대 a-b이므로 int 범위 안에 있다.
    int a;
    int b;
    cin >> a >> b;

    int operations = 0;

    // 목표 b에서 시작값 a를 향해 역연산을 수행한다.
    while (b > a) {
        if (b % 2 == 0) {
            // 짝수는 정방향의 두 배 연산을 거꾸로 적용할 수 있다.
            b /= 2;
        } else {
            // 홀수는 두 배로 만들어질 수 없으므로 1 빼기의 역연산을 적용한다.
            b += 1;
        }
        operations++;
    }

    // b가 a 이하가 되면 정방향에서 차이만큼 1을 빼면 도달한다.
    operations += a - b;

    cout << operations << '\n';
    return 0;
}
~~~

</Answer>

#### 예시 흐름

입력 a=3, b=10을 목표에서 시작점 방향으로 추적하면 다음과 같습니다.

~~~text
10 → 5  : 짝수이므로 2로 나누기
5 → 6   : 홀수이므로 1 더하기
6 → 3   : 짝수이므로 2로 나누기
~~~

총 3번이며, 이를 정방향으로 뒤집으면 3 → 6 → 5 → 10입니다.

#### 복잡도

- 시간 복잡도: O(log b) - 남은 차이는 반복하지 않고 한 번에 더합니다.
- 공간 복잡도: O(1)
