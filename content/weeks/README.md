# 강의노트 파일 안내

- 각 주차의 첫 강의는 `week-00.md`, 추가 강의는 `week-00-02.md`, `week-00-03.md` 형식으로 넣습니다.
- 0주차부터 사용할 수 있으며 주차와 강의 번호순으로 자동 정렬됩니다.
- 화면에 표시할 강의 제목은 `titles.json`에 파일명과 같은 키로 설정합니다.
- Markdown 안의 `#`, `##`, `###` 제목은 본문과 오른쪽 목차에 표시됩니다.
- `week-4.md`와 `week-04-01.md`처럼 같은 주차·강의 번호의 파일을 동시에 두면 중복 오류가 발생합니다.
- 이 README와 `week-숫자.md`, `week-숫자-강의번호.md` 형식이 아닌 파일은 강의 목록에서 제외됩니다.
- 초안은 이 폴더 밖에 보관합니다.

로컬 개발 서버는 파일 변경을 감지합니다. Vercel 사이트에는 GitHub push 후 새 배포가 완료되어야 변경 내용이 반영됩니다.
