## 컴파일러

```text
C++ 프로그램 → C++ 컴파일러 → 기계어 프로그램(.exe)
```

- C++ 프로그램은 텍스트 편집기나 개발 환경을 이용해 작성함.
- 컴파일러가 C++ 코드를 컴퓨터가 실행할 수 있는 기계어 프로그램으로 변환함.

## C++의 Hello World

```cpp
// Hello World program
#include <iostream>

int main() {
    std::cout << "Hello World" << std::endl;
    return 0;
}
```

### 설명
- `// Hello World program`
  - 주석
- `#include <iostream>`
  - 입출력 라이브러리의 기능을 포함함.
- `int main()`
  - 특별한 함수인 `main()`의 정의를 시작.
- `std::cout`
  - 문자열을 출력함.
- `std::endl`
  - 줄을 바꾸고 입출력 버퍼를 비움(flush).
- `return 0`
  - 프로그램 종료 상태 코드를 반환.
  - 일반적으로 `0`은 정상 종료를 의미함.

---

## 주석 Comments
- 주석은 프로그램을 설명하거나 명확하게 하기 위한 코드 속 메모.
- 컴파일러는 주석을 무시함.

```cpp
// ...
```

- `//` 이후의 모든 내용은 무시됨.

```cpp
/* ... */
```

- `/*`와 `*/` 사이의 모든 내용은 무시됨.

---

## 주석 예시

```cpp
// 정재의 과제

#include <iostream>

/*
아 공부하기 싫다
*/

int main() {
    std::cout << "Hello World" << std::endl;
}
```



## C++ 전처리기
- 전처리기(preprocessor)는 실제 컴파일 전에 실행됨.
- `#`으로 시작하는 지시문을 처리함.
- 파일을 포함하거나,
- 매크로를 정의하거나,
- 조건에 따라 특정 코드만 컴파일하도록 할 수 있음.

이를 통해 프로그램을 더 유연하고 모듈화할 수 있음.

전처리기를 직접 실행할 필요는 없으며 자동으로 수행됨.

---

## 전처리 과정

전체 흐름:

```text
C++ 프로그램 → C++ 전처리기 → 임시 C++ 파일 → C++ 컴파일러 → 실행 프로그램
```

즉, **전처리가 먼저 수행되고 그 결과물이 컴파일됨.**

---

## 전처리 지시문
**전처리 지시문(preprocessor directive)**은 C/C++ 전처리기에게 명령을 전달하는 문장.

항상 `#` 문자로 시작함.

예:

```cpp
#include <standard header file>
#define NAME value
```

---

## `#include` 매크로

```cpp
#include <filename.h>
```

- 실제 컴파일이 시작되기 전에 `filename.h` 파일의 내용을 현재 파일 안에 삽입함.

대표적인 예:

```cpp
#include <iostream>
```

- 표준 입출력 스트림 라이브러리를 포함하도록 전처리기에게 지시.
- 다음과 같은 기능을 사용할 수 있게 됨.
  - `std::cin`
  - `std::cout`
  - `std::cerr`

---

## `#define` 매크로

`#define`은 컴파일 전에 특정 이름을 값이나 코드로 치환하는 **전처리기 매크로**를 생성함.

예:

```cpp
#define NUM 45

y = NUM + NUM;
```

전처리 후:

```cpp
y = 45 + 45;
```

---

## 매개변수가 있는 `#define`

형식:

```cpp
#define identifier(identifier, ..., identifier) token_string
```

예:

```cpp
#define SQUARE(x) ((x) * (x))
```

사용:

```cpp
SQUARE(i+2)
```

전처리 후:

```cpp
((i+2)*(i+2))
```

## C++ 전처리문 정리

- `#include`
  - 헤더 파일 포함
- `#define`
  - 매크로 / 상수 정의
- `#undef`
  - 정의된 매크로 해제
- `#if / #elif`
  - 조건부 컴파일
  - `#else`, `#endif`와 함께 사용
- `#ifdef`
  - 특정 매크로가 정의되어 있는지 확인
- `#ifndef`
  - 특정 매크로가 정의되어 있지 않은지 확인
- `#error`
  - 컴파일 오류 발생
- `#pragma`
  - 컴파일러별 특수 명령

##  변수를 사용한 예제

```cpp
#include <iostream>
#include <string>

int main() {
    int age = 20;
    double height = 1.75;
    std::string name = "Alex";

    std::cout << name << " 는 " << age
              << "살이고 키는 "

}
```

### 설명
- `<string>`
  - 문자열 처리를 위한 클래스와 함수를 포함함.
- `age`, `height`, `name`
  - 변수.

OUTPUT:
> Alex는 20살이고 키는 1.75m이다.

##  리터럴 Literals

**리터럴(literal)**은 프로그램에서 직접 사용하는 고정된 값.

C++에서 리터럴은 작성 형태에 따라 자동으로 자료형을 가짐.

예:

```cpp
42      // int
3.14    // double
'A'     // char
```

추가 예:

```cpp
0x2A
false
"Hi Dave"
```

## 변수
- 변수는 반드시 **선언/정의**되어야 함.

예:

```cpp
int i, sum;
```

- 변수는 메모리 위치에 붙여진 이름이라고 볼 수 있음.
- 변수는 반드시 **자료형(type)**을 가져야 함.
- 사용하기 전에 반드시 선언해야 함.
- 정의하면서 초기화할 수도 있음.

예:

```cpp
int i = 5;
```

##  변수 이름

C++ 변수 이름 규칙:
- 문자, 숫자, `_`로 구성 가능.
- 숫자로 시작할 수 없음.
- 대소문자를 구분함.

따라서:

```cpp
foo
Foo
```

는 서로 다른 이름.

- 길이 제한은 사실상 없음.
- 좋은 변수 이름은 해당 변수가 무엇을 위해 사용되는지 알 수 있어야 함.

## C++의 주요 자료형

- `char`
  - 한 바이트 크기의 값, 일반적으로 문자 하나 저장

## 현대 C++의 정수 자료형

C++는 `<cstdint>`를 통해 **고정 크기 정수형**을 제공함.

```cpp
int8_t / uint8_t
```

→ 8비트 signed / unsigned

```cpp
int16_t / uint16_t
```

→ 16비트

```cpp
int32_t / uint32_t
```

→ 32비트

```cpp
int64_t / uint64_t
```

→ 64비트

### 장점
- 정수 크기를 명확하게 지정할 수 있음.
- 플랫폼 간 이식성이 향상됨.
- 일반적인 `int`, `long`의 크기 차이에서 생기는 모호함을 줄임.

## C++의 Boolean 논리
- C++의 논리 처리 방식은 C에서 이어받음.
- `0`은 false로 취급.
- `0이 아닌 값`은 true로 취급.

이는 정수와 논리값의 관계를 보여줌.

논리 리터럴:

```cpp
true
false
```

조건을 조합하기 위한 연산자:

```cpp
&&   // AND
||   // OR
!    // NOT
```

`if`, `while`, `for` 등의 흐름 제어에 사용됨.

## `bool` 자료형

`bool`은 다음 두 값만 저장함.

```cpp
true
false
```

내부적으로:

```cpp
true = 1
false = 0
```

- 정수와 암시적으로 변환될 수 있음.
- 일반적으로 크기는 1바이트.

## 정수 덧셈 프로그램

```cpp
#include <iostream>

int main() {
    int integer1, integer2, sum;

    std::cout << "Enter first integer\n";
    std::cin >> integer1;

    std::cout << "Enter second integer\n";
    std::cin >> integer2;

    sum = integer1 + integer2;

    std::cout << "Sum is " << sum << std::endl;

    return 0;
}
```

### 번역
- 첫 번째 정수를 입력하세요.
- 두 번째 정수를 입력하세요.
- 합은 `sum`입니다.

## `std::cin`을 이용한 입력

`std::cin`
- 키보드를 통해 사용자 입력을 읽는 데 사용.

`>>` **추출 연산자(extraction operator)**와 함께 사용하여 입력값을 변수에 저장함.

예:

```cpp
int age;
std::cin >> age;
```

사용자가 입력한 숫자가 `age`에 저장됨.

여러 값도 가능:

```cpp
int x, y;
std::cin >> x >> y;
```

입력에는 자료형 검사가 적용됨.  
잘못된 자료형을 입력하면 예상하지 못한 동작이 발생할 수 있음.

## 수학 표현식

**수학 표현식(mathematical expression)**은 변수, 상수, 산술 연산자를 결합하여 값을 계산함.

예:

```cpp
1 + 2
```

```cpp
(fahr - 32) * (5 / 9)
```

```cpp
1 * (2 * (i * (j * k)))
```

---

## 산술 연산자

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---:|
| `+` | 덧셈 | `5 + 3` | 8 |
| `-` | 뺄셈 | `5 - 3` | 2 |
| `*` | 곱셈 | `5 * 3` | 15 |
| `/` | 나눗셈 | `6 / 3` | 2 |
| `%` | 나머지 | `5 % 3` | 2 |

---

## 수학 연산자

연산자에는 표현식을 어떤 순서로 계산할지를 결정하는 두 규칙이 있음.

- **precedence**: 연산자 우선순위
- **associativity**: 연산자 결합 방향

### Overflow 문제

C++에서:
- signed 정수 오버플로우
  - **undefined behavior, 정의되지 않은 동작**
- unsigned 정수 오버플로우
  - 값이 범위를 넘어가면 다시 처음부터 순환함.

오버플로우는:
- 버그
- 보안 문제
- 예측할 수 없는 동작

등의 원인이 될 수 있음.

C++20, C++23, C++26 초안에서도:
- signed overflow → 여전히 UB
- unsigned overflow → modular arithmetic 방식으로 순환
- 오버플로우를 자동으로 탐지하거나 막는 표준 기능은 없음.

---

## 오버플로우 추가 설명

signed 정수 예:

```cpp
int x = INT_MAX;
int y = x + 1;
```

→ 정의되지 않은 동작.

unsigned 정수:

```cpp
unsigned int a = UINT_MAX;
unsigned int b = a + 1;
```

→ `0`으로 돌아감.

---

## 대입 연산자

대입 연산자:

```cpp
=
```

오른쪽의 표현식 값을 왼쪽 변수에 저장함.

예:

```cpp
x = 13 - y;
```

대입 연산자는 우선순위가 매우 낮음.

또한 **오른쪽에서 왼쪽으로 결합**됨.

따라서:

```cpp
x = y = z + 15;
```

와 같은 표현도 가능함.

실질적으로:

```cpp
y = z + 15;
x = y;
```

---

## 관계 연산자와 동등 비교 연산자

값을 비교하고 `true` 또는 `false`를 반환함.

| 연산자 | 의미 | 예 | 결과 |
|---|---|---|---|
| `<` | 작다 | `5 < 8` | true |
| `>` | 크다 | `5 > 8` | false |
| `<=` | 작거나 같다 | `5 <= 5` | true |
| `>=` | 크거나 같다 | `5 >= 8` | false |
| `==` | 같다 | `5 == 5` | true |
| `!=` | 같지 않다 | `5 != 8` | true |

## 결합 방향 Associativity

연산자의 **결합 방향**은 같은 연산자가 여러 번 등장했을 때 어떤 순서로 계산할지를 결정함.

예:

```cpp
3 / 4 / 5
```

결합 방향:
- **왼쪽 → 오른쪽**
  - 가장 왼쪽 연산자부터 적용.
- **오른쪽 → 왼쪽**
  - 가장 오른쪽 연산자부터 적용.
  - 여기서는 대입 연산자를 대표적인 예로 설명함.

---

## 우선순위 Precedence

**우선순위**는 여러 종류의 연산자가 있을 때 어떤 연산을 먼저 수행하는지를 결정함.

- 우선순위가 높은 연산자가 먼저 계산됨.
- 서로 다른 연산자가 같은 우선순위를 가진다면 **결합 방향 규칙**을 적용함.

---

## 연산자 우선순위

높은 순서부터:

```text
()
* / %
+ -
< <= > >=
== !=
=
```

즉:
- `()`가 가장 먼저
- `=`가 가장 마지막에 적용됨.

문제:

```cpp
2 / 3 / 4 + 5
```

또 다른 문제:

```cpp
x = (7 * 3 / 4 - 2) * 5 == y
```

→ 각각 **우선순위와 결합 방향을 이용해 계산 순서를 판단**해야 함.

## 오늘의 마지막 프로그램

```cpp
#include <iostream>

int main()
{
    double fahr, celcius;

    std::cout << "Enter Temperature in Fahrenheit\n";
    std::cin >> fahr;

    celcius = (fahr - 32.0)*5.0/9.0;

    std::cout << fahr << " fahrenheit is "
              << celcius << " Celcius"
              << std::endl;

    return 0;
}
```

### 번역
- 화씨 온도를 입력하세요.
- 입력된 화씨 온도를 섭씨 온도로 변환함.

공식:

`C = (F - 32) × 5 / 9`

출력 예:

```text
68 fahrenheit is 20 Celcius
```
