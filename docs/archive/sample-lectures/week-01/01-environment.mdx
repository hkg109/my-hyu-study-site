# 개발환경 준비하기

프로그래밍의 첫 단계는 코드를 작성하고 실행하는 환경을 갖추는 것입니다. 이번 강의에서는 아주 짧은 프로그램을 실행하며 C++ 개발의 흐름을 익힙니다.

<Callout>이 강의는 사이트 사용을 위한 샘플 강의입니다. 실제 스터디 PPT를 바탕으로 작성한 자료는 아닙니다.</Callout>

## 1. 코드가 실행되기까지

우리가 작성하는 `.cpp` 파일은 텍스트로 된 **소스 코드**입니다. 컴파일러는 이 코드를 번역하고, 링커는 필요한 코드들을 연결해 실행 파일을 만듭니다.

1. 편집기에서 소스 코드를 작성합니다.
2. 컴파일러로 코드를 번역합니다.
3. 링크를 거쳐 실행 파일을 만듭니다.
4. 실행 결과를 확인하고 코드를 수정합니다.

### 편집기와 컴파일러

편집기는 코드를 쓰는 도구이고, 컴파일러는 그 코드를 번역하는 도구입니다. 통합 개발 환경(IDE)은 편집, 빌드, 디버깅 기능을 한곳에서 제공합니다.

| 도구 | 역할 |
| --- | --- |
| 편집기 | 소스 코드 작성과 수정 |
| 컴파일러 | C++ 코드를 기계가 실행할 수 있는 형태로 번역 |
| 디버거 | 프로그램을 멈추고 변수와 실행 흐름 확인 |

## 2. 첫 번째 프로그램

스터디에서 안내받은 C++ 개발환경을 준비한 뒤, `hello.cpp`라는 파일에 아래 코드를 작성해 보세요.

```cpp title="hello.cpp" showLineNumbers {4}
#include <iostream>

int main() {
    std::cout << "Hello, C++!\n";
    return 0;
}
```

지금은 모든 문법을 외우지 않아도 괜찮습니다. 프로그램을 실행했을 때 화면에 `Hello, C++!`가 출력되는지 확인하는 것이 목표입니다.

### 터미널에서 실행하기

GCC의 C++ 컴파일러인 `g++`가 이미 설치되어 있다면 다음 명령으로 빌드할 수 있습니다.

```bash title="컴파일"
g++ -std=c++17 -Wall -Wextra hello.cpp -o hello
```

Windows PowerShell에서는 `./hello.exe`, macOS와 Linux에서는 `./hello`로 실행합니다. IDE를 사용한다면 해당 환경의 빌드와 실행 기능을 사용하세요.

<Callout type="warning">`g++`를 찾을 수 없다는 메시지가 나오면 컴파일러 설치 또는 PATH 설정을 먼저 확인하세요. 코드 자체의 오류와 개발환경의 오류는 구분해서 살펴봅니다.</Callout>

## 3. 자주 하는 실수

- 파일을 `hello.cpp.txt`로 저장하지 않았는지 확인합니다.
- 큰따옴표는 문서용 곡선 따옴표가 아닌 `"`를 사용합니다.
- 코드를 수정했다면 다시 빌드한 실행 파일을 실행합니다.
- 오류 메시지는 맨 위부터 읽습니다. 하나의 오타가 여러 오류를 만들 수 있습니다.

## 4. 직접 해보기

출력 문장을 `Hello, FORIF!`로 바꿔서 다시 실행해 보세요. 실행 결과가 바뀌지 않았다면 어떤 단계를 빠뜨렸을까요?

<Answer>

코드를 저장한 뒤 다시 컴파일해야 합니다. 소스 파일을 수정해도 이전에 만들어진 실행 파일은 자동으로 바뀌지 않습니다.

```cpp
std::cout << "Hello, FORIF!\n";
```

</Answer>

## 5. 핵심 정리

- 소스 코드는 사람이 읽고 수정하는 텍스트입니다.
- 컴파일과 링크를 거쳐 실행 파일을 만듭니다.
- 코드를 수정했다면 저장하고 다시 빌드합니다.
