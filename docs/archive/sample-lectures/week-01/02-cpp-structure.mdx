# C++ 프로그램의 구조

첫 프로그램을 실행했다면 이제 그 안의 각 줄이 어떤 역할을 하는지 살펴봅시다. 이 페이지는 기본 문법을 설명하기 위해 작성한 샘플 강의입니다.

## 1. 프로그램의 시작점

일반적인 C++ 실행 프로그램은 `main` 함수에서 작성한 작업을 시작합니다. 중괄호 안에는 실행할 문장들이 들어갑니다.

```cpp title="main.cpp" showLineNumbers {3,5}
#include <iostream>

int main() {
    std::cout << "One step at a time.\n";
    return 0;
}
```

`int`는 이 함수가 정수를 반환한다는 뜻입니다. `return 0;`은 정상 종료를 나타냅니다. `main`의 끝에 도달하면 명시적인 `return 0;`이 없어도 같은 의미로 처리됩니다.

## 2. 헤더와 이름 공간

`#include <iostream>`은 표준 입출력 기능을 사용할 수 있도록 관련 선언을 포함합니다. `std::cout`의 `std::`는 표준 라이브러리 이름 공간에 있는 `cout`을 사용한다는 뜻입니다.

### C와 비교하기

C에서 `printf`를 사용하는 것처럼, C++에서는 `std::cout`으로 값을 출력할 수 있습니다. 둘은 사용법과 처리 방식이 다릅니다. 다음 강의에서 C++ 스트림 입출력을 직접 사용합니다.

## 3. 문장과 블록

많은 C++ 문장은 세미콜론으로 끝납니다. 중괄호는 여러 문장을 하나의 **블록**으로 묶습니다.

```cpp title="statements.cpp"
int count = 3;
count = count + 1;
std::cout << count << '\n';
```

위 코드는 필요한 헤더와 `main` 함수 내부에서 실행하는 예제 조각입니다. 출력은 `4`입니다.

<Callout type="warning">모든 줄 끝에 세미콜론을 붙이는 것은 아닙니다. `#include` 지시문이나 함수 정의의 닫는 중괄호 뒤에는 세미콜론이 필요하지 않습니다.</Callout>

## 4. 주석 작성하기

주석은 실행할 명령이 아니라 코드를 읽는 사람을 위한 설명입니다.

```cpp title="comments.cpp"
// 한 줄 주석: 이 줄의 끝까지 주석입니다.
int count = 3;

/* 여러 줄에 걸친
   설명을 작성할 수 있습니다. */
```

주석에는 코드가 무엇을 하는지뿐 아니라 **왜 그렇게 작성했는지** 적으면 도움이 됩니다.

## 5. 연습문제

아래 코드가 컴파일되지 않는 이유를 찾아보세요.

```cpp title="find-the-error.cpp" showLineNumbers
#include <iostream>

int main() {
    std::cout << "C++ Study"
    return 0;
}
```

<Answer>

출력 문장 끝의 세미콜론이 빠져 있습니다.

```cpp
std::cout << "C++ Study";
```

오류가 표시된 줄 바로 앞의 문장도 확인하는 습관을 들이세요.

</Answer>

## 6. 핵심 정리

- `main` 함수는 프로그램의 시작점입니다.
- 헤더를 포함해 표준 라이브러리 기능을 사용합니다.
- 문장의 끝과 블록의 범위를 정확하게 표시합니다.
- 주석으로 코드의 의도를 전달합니다.
