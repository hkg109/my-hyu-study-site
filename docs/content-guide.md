# 콘텐츠 관리 안내

## 관리자 화면에서 관리하기

로컬에서 `npm run dev`를 실행한 뒤 헤더의 `관리자` 버튼으로 관리자 모드를 켭니다.

왼쪽 메뉴에서 다음 작업을 할 수 있습니다.

- `COURSE NOTES` 옆 `+`: 학년 추가
- 학년 옆 `+`: 해당 학년에 학기 추가
- 학기 옆 `+`: 해당 학기에 과목 추가
- 과목 옆 `+`: 해당 과목에 강의 노트 추가
- 각 분류 옆 연필: 화면에 표시되는 이름 수정

과목 옆 `+`를 누르면 제목과 템플릿을 고르는 창이 열립니다. 만들면 Markdown 파일과 필수 frontmatter가 자동 생성되고 해당 편집 화면으로 이동합니다. 템플릿 종류와 내용은 `lib/note-templates.ts` 한 파일에서 수정하거나 추가합니다.

## 강의 노트 파일

새 파일은 다음 위치에 생성됩니다.

```text
content/lectures/<gradeId>/<semesterId>/<subjectId>/lecture-01.md
```

예시:

```md
---
title: 행렬의 기본 연산
description: 행렬의 덧셈과 곱셈을 정리합니다.
order: 1
published: true
tags:
  - 선형대수
objectives:
  - 행렬의 기본 연산을 설명할 수 있다.
---

# 행렬의 기본 연산

여기에 학습 내용을 작성합니다.
```

- `order`: 같은 과목 안의 강의 순서
- `published`: `true`인 문서만 사이트에 표시
- `description`, `tags`, `objectives`, `duration`: 선택 항목
- 분류 이름은 파일에 복사하지 않고 `catalog.json`의 안정적인 ID로 연결되므로 이름을 수정해도 기존 URL이 유지됩니다.

## 족보 파일

족보 탭도 강의 정리와 같은 학년·학기·과목 카테고리를 사용합니다. 관리자 모드에서 원하는 과목의 `+` 버튼을 누르고 템플릿(빈 노트·객관식 족보·서술형 족보)과 접근 방식을 고르면 `content/practice/<gradeId>/<semesterId>/<subjectId>/exam-NN.md` 형식으로 생성됩니다. 비밀번호는 파일에 적지 않고 `accessKey`로 환경변수에 연결합니다([README의 비밀번호 설정](../README.md#비밀번호-설정) 참고). `.mdx` 파일은 족보로 불러오지 않으며, 제목, 설명과 본문은 관리자 화면에서 수정할 수 있습니다. 일반 Markdown 파일은 MD로 처리하고, 기존 `<Answer>` 같은 확장 컴포넌트가 포함된 `.md`만 호환을 위해 자동으로 확장 문법을 해석합니다.

```md
---
title: 과목 중간고사 족보
description: 중간고사 문제와 해설입니다.
order: 1
published: true
---

## 문제 1

문제 내용을 작성합니다.

<Answer>

해설을 작성합니다.

</Answer>
```

예전 파일에 남아 있는 `week` 값은 더 이상 쓰지 않으므로 지워도 됩니다.

## 교재형 박스와 인쇄

강의 노트에서 아래 표시를 쓰면 웹과 PDF에서 같은 모양의 박스로 보입니다.

| 표시 | 박스 이름 | 용도 |
|---|---|---|
| `> [!CONCEPT]` | 개념 | 핵심 용어 정의 |
| `> [!BOARD]` | 판서 | 화살표·목록으로 압축한 한눈 정리 |
| `> [!NOTE]` | 해설 | 쉬운 설명과 사례 |
| `> [!TRAP]` | 오답 주의 | 시험에서 헷갈리는 구분 |
| `> [!PROBLEM]` | 예제 | 상황 문제와 단계별 풀이 |
| `> [!CHECK]` | 확인 문제 | 답은 단원 끝 "정답과 해설"에 모읍니다 |

```md
> [!CONCEPT]
> **Transaction cost** — 시장에서 거래할 때 드는 비용
```

- `> [!PAGEBREAK]`는 PDF에서 새 쪽을 시작합니다. 화면에는 보이지 않습니다.
- `{{정답}}`은 웹에서 눌러서 확인하는 빈칸이 되고, PDF에서는 빈 밑줄로 인쇄됩니다.

## 족보 PDF (시험지 양식)

족보 페이지의 **PDF로 저장**은 화면 그대로가 아니라 수능 시험지처럼 다시 짠 PDF를 만듭니다. 옆의 선택 상자에서 `시험지+정답·해설`(기본), `시험지만`, `정답·해설만`을 고릅니다.

- **문제지**: 맨 위에 족보 제목, `제 N 교시`(과목 안에서 이 족보의 순서), `<과목> 영역(<부제>)`, 성명·수험번호 칸이 들어가고 본문은 가운데 세로줄로 나눈 2단입니다. 과목 이름의 ` · ` 뒤 부분이 괄호 속 부제가 됩니다(예: `정시개 · 경영정보시스템` → `정시개 영역(경영정보시스템)`).
- **문항 인식**: `### 1. 제목`, `### 01 · 1 point`, `## 문제 3`, `## Question 2`처럼 **번호로 시작하는 제목**이 문항 하나입니다. 그보다 상위 제목(`## Part 1 · …`)은 문항 묶음 이름으로 인쇄되고, 문항이 없는 묶음(응시 안내, 출처 등)은 빠집니다. 제목에 `1 point`나 `` `2점` ``이 있으면 `[1점]`처럼 붙습니다.
- **문항 내용**: `[!QUIZ]` 블록이 문제 본문입니다. `[!QUIZ]` 앞에 적은 출처·복원 메모, 힌트, 번역, `[!EXAM]` 같은 상자는 인쇄하지 않습니다. 객관식 `**A.**`~`**E.**`는 ①~⑤로 바뀌고, 짧은 선택지는 한 줄에 모입니다. 객관식이 아닌 문항 아래에는 답 쓰는 칸이 생깁니다.
- **정답과 해설**: 새 쪽에서 시작합니다. 맨 위에 10문항씩 끊은 정답표가 있고, 그 아래 2단으로 `번호 · 제목 · [정답]`과 `[!ANSWER]`·`<Answer>`·`[!SOLUTION]` 내용이 이어집니다. 서술형의 정답표 칸에는 정답 첫 줄의 굵은 글씨(짧을 때만)나 `해설 참조`가 들어갑니다.
- 인쇄 창에서 **배경 그래픽**을 켜야 회색 칸이 보이고, 머리글/바닥글은 끄는 것이 좋습니다.

## 작성 시 주의사항

- ID와 파일명은 소문자 영문, 숫자, 하이픈만 사용합니다.
- 같은 과목 안에서 `order`를 중복해서 사용하지 않습니다.
- 새 분류와 노트 생성은 로컬 관리자 모드에서 수행합니다.
- `catalog.json`의 `id`를 직접 바꾸면 기존 URL과 파일 연결이 끊어질 수 있으므로 화면에서는 이름만 수정합니다.
